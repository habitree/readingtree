## 4. 보안 검증

- 인증 필요 라우트 35개 모두 미인증 시 `/login`으로 올바르게 리다이렉트
- `redirectedFrom` 파라미터로 원래 경로 보존 확인
- 게스트 접근 허용 라우트 (`/`, `/books`, `/notes`, `/groups` 등)는 정상 표시

## 5. 발견된 이슈

**Critical/Major/Minor: 없음**

### 개선 제안 (INFO 수준)
1. **로그인/회원가입 페이지 초기 로드** (3.1~3.2s) — Auth UI 번들 최적화 고려
2. **내 서재 페이지** (3.5s) — 도서 목록 초기 로드 최적화 고려
3. **`/books/search`** — constants에서 `requiresAuth: false`로 잘못 설정되어 있었음 → `true`로 수정 완료
