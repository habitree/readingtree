## 우선순위 액션 플랜

### 즉시 조치 (🔴 Critical) — 서비스 출시 전 필수

1. **법률 자문** — 선불전자지급수단 비해당 확인 (전자금융 전문 법률사무소)
2. **세무 자문** — 포인트 과세 시점·회계 처리 확정 (세무사)
3. **포인트 이용약관** 별도 작성 (성격, 유효기간, 소멸, 양도 불가, 환불)
4. 개인정보처리방침 작성 및 게시 (PG사 위탁 포함)
5. 이용약관 정비 (포인트 결제, AI, UGC, 미성년자 조항)
6. 사업자 정보 Footer 표시 + 통신판매업 신고
7. **환불 프로세스 구현** (7일 철회, 미사용분 환불, 다크패턴 방지)
8. **PG사 연동** (카드 정보 직접 저장 금지, 위탁 계약 체결)
9. **미성년자 보호** (만 14세 이상 제한 또는 법정대리인 동의 절차)
10. **유상/무상 포인트 DB 구분** (`acquisition_type` 컬럼 추가)
11. 동의 UI 분리 (필수/선택/마케팅)
12. RLS 전체 테이블 적용 확인

### 단기 조치 (🟡 Warning, 3개월)

13. AI 생성물 표시 전면 적용
14. 도서 표지 API 이용 계약 확인
15. 마케팅 수신 동의/거부 UI
16. 웹접근성 기초 항목 점검
17. 접속기록 보관 체계 정비
18. 포인트 소멸 사전 통지 시스템 (30일 전)
19. 발행잔액·총발행액 모니터링 대시보드

### 중장기 대비 (🔵 Advisory, 6~12개월)

20. 데이터 내보내기(전송요구권) 기능
21. UGC 신고/임시조치 절차
22. 스크린 리더 호환성 개선
23. GDPR 대비 (글로벌 확장 시)
24. 미성년자 자율 결제 한도 설정
25. PG 수수료 매입세액공제 확인
