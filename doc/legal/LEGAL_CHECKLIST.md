## 우선순위 액션 플랜

### 즉시 조치 (🔴 Critical)

1. 개인정보처리방침 작성 및 게시
2. 이용약관 정비 (결제, AI, UGC 조항)
3. 사업자 정보 Footer 표시
4. 통신판매업 신고 (유료 서비스 시)
5. 동의 UI 분리 (필수/선택/마케팅)
6. 구독 해지 UX 점검 (다크패턴)
7. RLS 전체 테이블 적용 확인

### 단기 조치 (🟡 Warning, 3개월)

8. AI 생성물 표시 전면 적용
9. 도서 표지 API 이용 계약 확인
10. 마케팅 수신 동의/거부 UI
11. 웹접근성 기초 항목 점검
12. 접속기록 보관 체계 정비

### 중장기 대비 (🔵 Advisory, 6~12개월)

13. 데이터 내보내기(전송요구권) 기능
14. UGC 신고/임시조치 절차
15. 스크린 리더 호환성 개선
16. GDPR 대비 (글로벌 확장 시)
