# Streaming SSR 대시보드 설명서

## 1. Streaming SSR이란 무엇인가요?
**Streaming SSR(서버 사이드 렌더링 스트리밍)**은 웹 페이지를 불러올 때, 모든 데이터가 준비될 때까지 기다리는 대신 **준비된 부분부터 즉시 화면에 보여주는 기술**입니다.

마치 동영상을 볼 때 전체 파일을 다 다운로드받은 뒤에 보는 것이 아니라, 다운로드되는 대로 바로 재생하는 '스트리밍' 방식과 같습니다.

---

## 2. 왜 대시보드에 필요한가요?
대시보드는 한 화면에 **도서 통계, 최근 읽은 책, 도서 추천, 사용자 활동** 등 매우 다양한 데이터를 동시에 보여줍니다.

*   **기존 방식:** 모든 통계 데이터와 추천 목록이 불러와질 때까지 하얀 화면만 보입니다. 만약 추천 엔진 데이터가 3초 걸린다면 사용자는 3초 동안 아무것도 못 봅니다.
*   **Streaming SSR 적용:** 먼저 준비된 기본 레이아웃과 데이터는 즉시 보여주고, 시간이 걸리는 '추천 목록'이나 '복잡한 차트' 부분은 '로딩 중(Skeleton)' 표시를 하다가 준비되는 대로 슥 나타납니다.

---

## 3. 주요 장점 (사용자가 느끼는 변화)

### ① 체감 속도 향상
*   사용자는 페이지를 누르자마자 무언가 나타나는 것을 봅니다. "로딩 중인가?" 하는 불안함 없이 즉각적인 반응을 느낄 수 있습니다.

### ② 중요한 정보 우선순위 제공
*   가장 중요한 기본 통계 수치나 메뉴 등은 먼저 보여주고, 계산이 복잡한 AI 리포트 같은 기능은 배경에서 천천히 불러옵니다.

### ③ 이탈률 감소
*   화면이 멈춰있는 시간이 없으므로 사용자가 페이지가 작동하지 않는다고 생각하여 나가는 상황을 방지합니다.

---

## 4. 실제 진행되는 작업 안내 (개발 과정)

1.  **Next.js Suspense 적용:** 화면의 각 요소 중 로딩이 오래 걸리는 부분을 `Suspense`라는 단위로 감쌉니다.
2.  **스켈레톤(Skeleton) 디자인 제작:** 데이터가 오기 전까지 해당 위치에 보여줄 '뼈대 이미지(회색 박스 등)'를 만듭니다.
3.  **데이터Fetching 분리:** 한 번에 모든 데이터를 가져오던 방식을 각 컴포넌트별로 필요한 만큼만 가져오도록 독립시킵니다.
4.  **Vercel 배포 최적화:** 스트리밍 방식이 원활하게 작동하도록 Vercel 서버 설정을 조정합니다.

---

## 5. 비개발자가 알아두어야 할 점
*   **디자인 중요성:** 데이터가 나오기 전의 모습(스켈레톤)도 디자인의 일부가 되므로, 이 부분이 부자연스럽지 않게 설계하는 것이 중요합니다.
*   **효율성:** 서버 리소스를 더 효율적으로 사용하여 많은 사용자가 동시 접속해도 안정적인 응답을 유지할 수 있습니다.
