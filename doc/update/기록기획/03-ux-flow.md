# 03 — UX 플로우

> 본 문서는 사용자가 보는 모든 시각·인터랙션 명세. 시각·디자인 토큰은 `lib/design-tokens.ts` 따름.

## 1. 핵심 멘탈 모델

```
[기록] = 시간 + 페이지 + 간단 메모 + 북마크 + 사진들
[상세기록] = 필사 / 구절 / 긴 생각 (텍스트 중심)
```

- 기록은 **세션** (시작-종료 구간).
- 상세기록은 세션에 종속(추천) 또는 자유(허용, D3).

---

## 2. 행복 경로 (Happy Path)

### 2.1 기록 시작 → 진행 중 → 종료

```
[홈/책상세 어디서든]
    │
    ▼
┌──────────────────┐
│ FAB "+ 기록"     │
└────────┬─────────┘
         │ 탭
         ▼
┌──────────────────────────┐
│ RecordSheet (start)      │
│ ─────────────────────────│
│ 책: [표지 + 제목 ▼]       │  ← 최근 책 prefill, ▼로 전환
│ 시작 페이지: [123]       │  ← getLastEndPage prefill
│ 시간: 15 / 25 / 45 / ∞   │  ← 프리셋 (선택, 무제한 가능)
│ ─────────────────────────│
│ [기록 시작]              │
└────────┬─────────────────┘
         │ startReadingSession
         ▼
┌──────────────────────┐
│ 시트 닫힘            │
│ FAB가 변형:          │
│  [12:34 📖] (책표지) │
└────────┬─────────────┘
         │ 인디케이터 탭 (또는 시간 만료)
         ▼
┌──────────────────────────┐
│ RecordSheet (end)        │
│ ─────────────────────────│
│ 책: [고정, 변경 불가]     │
│ 시작: 123  →  끝: [148]   │  ← 입력 필수
│ 메모 (선택): [____]      │  ← ≤200자
│ □ 북마크 추가             │  ← 토글
│   └ 메모: [____]          │
│   └ 페이지: [148]         │
│ 사진: [📷+] [📷+]         │  ← ≤5장
│ ─────────────────────────│
│ [취소]      [저장]       │
└────────┬─────────────────┘
         │ endReadingSession
         ▼
┌──────────────────────┐
│ Toast                │
│ "기록 저장 · 25분 · 25p"
│ [닫기] [상세 기록 추가] [공유*]
└──────────────────────┘
   * 사진 ≥1장일 때만
         │ "상세 기록 추가" (선택)
         ▼
┌──────────────────────────┐
│ RecordSheet (detail)     │
│ ─────────────────────────│
│ 종류: ○ 구절 ○ 생각 ○ 필사│
│ 본문: [____]             │
│ 페이지: [선택]            │
│ 태그: [#] [#]             │
│ ─────────────────────────│
│ [저장]                   │
└────────┬─────────────────┘
         │ addNoteToSession
         ▼
[Toast: "상세 기록 연결됨 +Xp"]
```

### 2.2 음악 타이머와의 결합

```
[음악 시트에서 "재생"]
    │
    ▼
┌─ useMusicPlayer.startTimer ─┐
│ 음악 + 카운트다운            │
└──────────────────────────────┘
    │ ── 동시에 ──
    ▼
[useReadingSession.start 자동 호출]
    │
    ▼
[기록 진행 중 + 음악 재생]
    │
    ▼ (시간 만료 또는 사용자 정지)
┌──────────────────────┐
│ ReadingCompleteDialog│
│ "기록하기" 탭 시      │
└────────┬─────────────┘
         │
         ▼
[RecordSheet (end) 자동 진입]
```

### 2.3 자유 상세기록 (D3 — 책 없음)

```
[/notes/free 또는 quickstart=true]
    │
    ▼
┌──────────────────────────┐
│ RecordSheet (detail 직진)│  ← start step 건너뜀
│ 종류·본문·태그           │
└────────┬─────────────────┘
         │ addNoteToSession(null, ...)
         ▼
[notes INSERT — reading_log_id NULL]
```

## 3. 인디케이터 표시 규칙 (D5 — 별도 영역)

| 상태 | 모바일 FAB | 데스크톱 헤더 | 음악 미니플레이어 |
|---|---|---|---|
| idle | `+ 기록` | (없음) | 음악 단독 |
| in_progress | `[12:34 📖]` | inline pill `[12:34 책제목]` | 음악 단독 (별도) |
| in_progress + 음악 | `[12:34 📖]` | 동일 | 음악 단독 (별도) |
| 음악만 | `+ 기록` | (없음) | 음악 단독 |

### 3.1 인디케이터 콘텐츠
- 시간: `MM:SS` (1시간 이상 시 `H:MM:SS`)
- 책 표지: 32×32 원형 (없으면 책 emoji)
- 색: `accent` (기본), 종료 5분 전 `warning`로 페이드, 만료 시 `destructive` 펄스

### 3.2 클릭 동작
- 모바일 FAB·데스크톱 pill 모두 → `RecordSheet (end)` 진입
- 길게 누름(모바일): "취소하기" 메뉴

## 4. 분기·예외 시나리오

### 4.1 시작 실패 (이미 진행 중)
```
사용자: FAB "+ 기록" 탭
시스템: getActiveSession() → 기존 세션 발견
액션: 시트 대신 즉시 end-step 진입 + 상단 안내 배너
       "이전 세션이 진행 중입니다. 종료할 페이지를 입력하세요."
```

### 4.2 다중 탭 동시 시작
```
탭 A: startReadingSession → 성공
탭 B: startReadingSession → unique 위반
탭 B 처리: 명확한 토스트
       "다른 탭에서 이미 기록을 시작했습니다. 새로고침 후 진행 중 세션을 확인하세요."
탭 B BroadcastChannel 수신 → 자동으로 인디케이터 표시
```

### 4.3 30초 미만 취소
```
사용자: 시작 직후 "취소" 또는 시트 dismiss
시스템: cancelActiveSession → 행 DELETE (기록으로 남기지 않음)
```

### 4.4 30초 이상 취소
```
사용자: 진행 중 "취소" 또는 long-press → "취소하기"
시스템: 확인 모달 "기록을 취소합니다. 시간은 저장되지 않습니다. [취소][확인]"
       확인 시 cancelActiveSession → status='abandoned' (감사 추적용)
```

### 4.5 12시간 이상 멈춘 세션
```
조건: started_at < NOW() - 12h AND status='in_progress'
처리: Phase 6 마이그(M5) 또는 daily cron으로 status='abandoned' 자동 전환
사용자: 다음 진입 시 인디케이터 사라지고 "이전 세션이 자동 종료되었습니다" 알림
```

### 4.6 게스트 (비로그인)
```
사용자: FAB "+ 기록" 탭
시스템: 인증 체크
액션: LoginPromptModal 표시 (기존 패턴 재사용)
```

### 4.7 책 없이 기록 (선택)
```
사용자: 책 ▼에서 "책 없음" 선택
시스템: user_book_id = READTREE_BOOK_ID 폴백
저장: 기록은 정상 저장, /stamps에는 표시 (책 정보 없이)
```

## 5. 상세기록 진입점

| 진입점 | 컨텍스트 | reading_log_id |
|---|---|---|
| 토스트 "상세 기록 추가" | 직전 종료 세션 | 자동 연결 |
| `/notes/new` | URL `?session=<id>` | 명시 연결 |
| `/notes/free` | 자유 | NULL (D3) |
| 책 상세 → "구절 추가" | 책만 연결, 세션 없음 | NULL (단 user_book_id는 set) |
| 사이드바 "상세기록" 메뉴 | 자유 | NULL |

## 6. 토스트·알림 사양

| 트리거 | 메시지 | 액션 |
|---|---|---|
| 기록 시작 | (없음, 시트 닫힘 + FAB 변형으로 충분) | — |
| 기록 종료 (사진 0장) | "기록 저장 · 25분 · 25p +Xp" | 닫기 / 상세 기록 추가 |
| 기록 종료 (사진 ≥1장) | "스탬프 +1 · 25분 · 25p +Xp" | 닫기 / 상세 기록 추가 / 공유 |
| 기록 취소 (30초 미만) | (조용히 닫음) | — |
| 기록 취소 (30초 이상) | "기록을 취소했습니다" | — |
| 음악 만료 + 진행 중 세션 | "독서 시간이 끝났어요. 종료 페이지를 입력하세요." | 종료 / 5분 더 / 취소 |
| 12h 자동 abandoned | "이전 기록이 자동으로 종료되었습니다." | 닫기 |
| 멱등 충돌 | "다른 탭에서 이미 시작했습니다." | 진행 중 보기 |

## 7. 빈 상태 (Empty State)

| 화면 | 상태 | UI |
|---|---|---|
| 책 상세 → 독서 시간 탭 | 기록 0건 | "첫 기록을 시작해보세요" + "+ 기록" 버튼 |
| `/stamps` | 스탬프 0건 | "기록에 사진을 추가하면 스탬프가 돼요" (기존 유지) |
| `/notes` | 상세기록 0건 | "구절·생각·필사를 자유롭게 남겨보세요" + "+ 상세기록" 버튼 |

## 8. 접근성

- 모든 시트는 `Esc`로 닫기.
- 인디케이터는 `aria-live="polite"`로 시간 변화 안내(1분 단위).
- 시간 카운트다운은 `prefers-reduced-motion` 시 텍스트만 (애니메이션 없음).
- 사진 업로드는 모바일 카메라/앨범 선택 가능.
