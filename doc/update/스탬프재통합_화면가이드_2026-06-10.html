스탬프 재통합 — 어디가 어떻게 바뀌었나

"시간을 기록한 뒤 사진을 더하면 스탬프가 된다." 카나리(NEXT_PUBLIC_RECORD_V2)가 기본 ON으로 바뀌어 모든 기록 진입점이 새 RecordSheet를 사용합니다. 아래는 실제로 바뀐 메뉴·화면을 진입점별로 정리한 것입니다.

1 기록 진입점 — 새 RecordSheet로 통일

"기록/스탬프" 버튼들이 모두 같은 시트로 모임 (카나리 ON 효과)

모바일 + · 사이드바 · 퀵액션 · /stamps → 기록 시작 시트
  • 변경 전: 진입점마다 NEXT_PUBLIC_RECORD_V2가 OFF라 구형 StampCaptureSheet(사진 강조)로 열림.
  • 변경 후: 기본 ON → 모든 진입점이 RecordSheet "기록 시작"으로 통일. 책·시작 페이지 확인 후 시작 → 종료 시 페이지·메모·사진 입력.
  • 대상 메뉴: 모바일 하단 + 버튼, 사이드바 "기록하기", 대시보드 모바일 퀵액션, /stamps 컬렉션 캡처 버튼.
  • 스탬프 컬렉션(/stamps)·공유 페이지(/share/stamps/[id])는 그대로.

2 기록 종료 토스트 — "사진 추가" 동선 신설

시간만 저장해도 나중에 사진을 더해 스탬프로 만들 수 있게

기록 종료 시트 → 저장 → 토스트 액션
  • 사진 없이 저장 → 토스트에 "사진 추가" 버튼. 누르면 ③ 사진 추가 시트가 그 기록을 대상으로 열림.
  • 사진과 함께 저장(이미 스탬프) → 토스트에 "공유" 버튼.
  • 포인트는 종료 시 1회만 적립(사후 사진 추가는 추가 적립 없음 · D4 불변).

3 사진 추가 시트 — 신규 화면

기존 기록에 사진을 더해 스탬프로 승격 (페이지·메모도 같이 수정)

토스트 "사진 추가" · 독서 시간 탭 · 내 독서 속도 → 사진 추가 시트
  • 제목 "사진 추가" · "이 기록에 사진을 더하면 스탬프가 돼요. 페이지·메모도 함께 수정할 수 있어요."
  • 사진 1장 이상 → 버튼 "스탬프 남기기" → 저장 시 그 기록이 스탬프로 승격(저장 후 "공유" 토스트).
  • 사진 없이 페이지·메모만 → 버튼 "저장"(단순 수정).
  • 여러 진입점에서 같은 시트 재사용(토스트, 독서 시간 탭 편집, 내 독서 속도 "사진" 칩).

4 책 상세 · 독서 시간 탭 — 편집 동선 통일

각 기록 행의 "편집"이 새 사진 추가 시트로 진입

책 상세 › 독서 시간 탭 › 기록 행 편집
  • 카나리 ON → "편집" 클릭 시 RecordSheet(사진 추가)로 진입(OFF면 기존 시트).
  • 시트 안에서 사진/페이지/메모 자유 수정 — 사진 없이도 저장 가능.
  • 기록 목록·통계 표시 자체는 동일(동선만 새 시트로 통일).

5 내 독서 속도 — 내 기록 통합 뷰 ⭐

시간·페이지·스탬프·메모를 한 화면에서 관리 (요청 "내 기록 관리"의 핵심)

프로필 › 내 독서 속도 (/profile/reading-speed)
  • 세그먼트 필터 [전체 · 시간만 · 스탬프] 신설 — 스탬프만 모아 보기 가능.
  • 각 기록 카드에 사진 썸네일 + "스탬프" 배지. 사진 없으면 "📷 사진" 칩 → 사진 추가 시트.
  • 메모가 카드에 표시되고, "수정" 폼에서 인라인 편집(페이지·시간과 함께).
  • 썸네일 탭 → 라이트박스(좌우/Esc). 사진 추가 후 목록 자동 갱신.
  • 기존 기능(평균 속도·이상치 배지·속도 가이드 범위·"페이지 추가")은 그대로 유지.
