스탬프 재통합 + 독서 기록 시스템 정리

"스탬프는 새 기능이 아니라, 시간을 기록한 세션에 사진을 더한 한 상태다."

2026-04-30 통합 기획은 구(舊) 스탬프 시트 위에서 그려졌습니다. 그 뒤 도입된 세션 모델(RecordSheet) 위에서 "시간 기록 → 사진 승격 → 스탬프 관리"를 다시 잇고, 흩어진 기록 기능을 묶어 정리합니다.

1 왜 다시 기획하나 — 갭의 정체

스탬프는 이미 구현됐다. 문제는 "구 경로와 새 세션 모델의 이원화"다.

이미 있는 것 — 스탬프 = 사진 첨부된 reading_logs 행. 생성/조회/공유 액션, /stamps 컬렉션, /share/stamps/[id] 공개 페이지, 8개 컴포넌트, promoted_at(사후 승격 시각) 컬럼까지 모두 구현 완료.
① 이원화
구: StampCaptureSheet + createReadingStamp · 신: RecordSheet + endReadingSession. 카나리 NEXT_PUBLIC_RECORD_V2 OFF로 둘이 공존(분기 5곳).
② attach 모드 누락
새 RecordSheet엔 사후 사진 첨부 흐름이 없음. 사후 첨부는 아직 구 StampCaptureSheet만 가능.
③ "사진 추가" 진입점 미연결
record-end-step 종료 토스트엔 "공유"만. stamp-toast.ts의 onAddPhoto 슬롯이 비어 있음.
④ 미배선 액션
getRecentRecordsForAttach 호출처 0건. "최근 기록에 사진 추가" 진입이 어디에도 안 붙음.
📌 기존 doc/update/기록기획/ 로드맵(묶음1~5: A5·A3·C7·C8·C9·B1…)에는 스탬프 재통합 항목 자체가 없습니다. 본 기획이 그 빈 칸을 채웁니다. (사용자 메모 260604_기록관련 정리.md: "독서시간/진행률/여정 3축 정리", "내 기록에 독서시간·페이지별 관리")

3 단일 흐름 — 시간 기록 이후 스탬프 관리

"별도의 스탬프"가 아니라 "시간 기록 → (선택) 사진 승격 → 관리"의 한 줄기

1
기록 시작 · startReadingSession
status='in_progress' · start_page = max(current_page, 직전 end_page) 자동 승계 · 사용자당 1개(D2)
2
기록 종료 · endReadingSession(end_page, memo, image_urls?)
사진 있음 → 트리거가 image_url 미러 + promoted_at 즉시 설정 = 스탬프 · 사진 없음 → 시간·페이지만 저장 + updateBookProgress(진행률 동기화)
3
사후 승격 · attachStampToLog(logId, {image_urls, page?, memo?})
"어제 시간만 기록한 세션"에 오늘 사진을 추가 → promoted_at 첫 전환 · 포인트 추가 적립 없음(D4)
4
관리 · /stamps 컬렉션 · /share/stamps/[id] 공유 · 내 기록 통합 뷰
스탬프 필터 = image_url≠NULL (정의 불변, 어디서나 동일)

4 스탬프 재통합 설계 ★ (Phase B — 본 기획의 메인)

새 세션 모델(RecordSheet)에 사후 첨부(attach)를 잇고, 종료 후 진입점을 연결

변경 요약

  • 4.1 종료 시 즉시 승격 — 이미 구현(endReadingSession({image_urls}) → 트리거). 정식 경로로 확정.
  • 4.2 RecordSheet attach 모드 신설 — use-record-sheet.ts에 mode:"attach" + openAttach(logId, options), 신규 components/records/record-attach-step.tsx(사진 → attachStampToLog / 페이지·메모 → updateReadingLogEntry), record-sheet.tsx 라우팅.
  • 4.3 종료 후 "사진 추가" 진입점 — 사진 없이 저장 시 토스트 액션 onAddPhoto → openAttach(sessionId) 연결.
  • 4.4 reading-time-tab 카나리 분기 — openEditSheet를 isRecordV2Enabled()로 분기(ON→openAttach, OFF→legacy).
  • 4.5 getRecentRecordsForAttach 활성화 — 통합 뷰·시간탭의 "최근 기록에 사진 추가" 진입에 연결.

9 결정 정합성 — 기존 ADR/DEC와 충돌 없음

기존 합의를 깨지 않음을 명시

D2 · in_progress 1개
attach는 완료된 세션 대상이라 진행 중 세션 정책과 무관.
D4 · 포인트 종료 1회
attachStampToLog는 추가 적립 없음 — 정책 불변. 사진 보너스 도입은 별도 결정.
DEC-6 · 여정 편입
스탬프 승격(사진)은 여정 점 판정(end_page 전진)과 독립 — 충돌 없음.
스탬프 정의
image_url≠NULL AND promoted_at≠NULL — 00-master.md와 동일하게 유지(불변).
기존 공유 자산
/stamps · /share/stamps/[id] · stamp-share-* · 컬렉션 그리드는 모두 유지 — 제거 대상은 구 입력 시트뿐.
