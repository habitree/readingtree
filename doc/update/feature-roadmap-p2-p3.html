[X-5] 인앱 알림 시스템

모임 활동, 스트릭 위험, 완독 축하, AI 리포트 완성 등에 대한 인앱 알림. 현재 알림 시스템 0% 구현.

구현 범위:
- notifications 테이블 생성 (user_id, type, title, body, read, created_at)
- 헤더에 알림 벨 아이콘 + 읽지 않은 개수 뱃지
- 알림 드롭다운/페이지 (마크 올 리드)
- 트리거: 모임 새 공유/댓글, 스트릭 2일 남음, 완독 축하, AI 리포트 완성

관련 파일: app/actions/notifications.ts (신규), components/layout/header.tsx, DB 마이그레이션
P2 영향도 중간 난이도 중간

[G-1] 모임 발견/추천 개선

공개 모임 목록에 "추천 모임", "인기 모임", "최근 활발한 모임" 정렬 추가. 현재 단순 나열.

구현 방향:
- 모임 목록 정렬 옵션: 최신순, 멤버 수 순, 최근 활동 순
- "추천" 로직: 사용자가 읽는 책 장르와 모임 지정도서 매칭

관련 파일: components/groups/groups-content.tsx, app/actions/groups/core.ts
P2 영향도 중간 난이도 높음

[G-2] 모임 내 독서 챌린지

"이번 달 OO책 함께 읽기" 같은 기한 있는 공동 목표 기능. 현재 지정도서만 있고 기한/목표 설정 없음.

구현 범위:
- group_challenges 테이블: group_id, title, book_id, start_date, end_date, goal_type (pages/complete)
- 모임 대시보드에 챌린지 카드 (진행률 바, 참여 멤버 아바타)
- 챌린지 완료 시 포인트 보너스

관련 파일: app/actions/groups/ (신규 challenges.ts), components/groups/group-dashboard.tsx
P2 영향도 중간 난이도 낮음

[AI-1] AI 채팅 진입점 다양화

책 상세 페이지에서 "이 책에 대해 물어보기" 버튼 추가. 현재 /chat으로만 접근 가능.

구현:
- 책 상세 액션 바에 AI 아이콘 버튼 추가
- 클릭 시 /chat?bookId={id}로 이동, 채팅 세션에 책 컨텍스트 자동 설정

관련 파일: 책 상세 페이지 액션 바, app/(main)/chat/page.tsx
P2 영향도 중간 난이도 중간

[P-2] 주간 미션 추가

일일 미션만 있고 주간 챌린지 없음. "이번 주 3권 기록" 같은 중기 목표로 재방문 유도.

구현 범위:
- weekly_missions 또는 기존 daily_missions 확장 (period: daily/weekly)
- 주간 미션 3개: 기록 5개 작성, 새 책 1권 추가, 3일 연속 활동
- 포인트 대시보드에 주간 미션 섹션 추가

관련 파일: app/actions/points.ts, components/points/points-page-content.tsx
P2 영향도 중간 난이도 높음

[X-4] 통합 검색 (책+기록+모임)

현재 검색은 /notes?q= 리다이렉트만. 책/기록/모임을 동시에 검색하는 통합 검색 결과 페이지.

구현 방향:
- /search?q= 페이지에서 탭별 결과: 기록(N) / 책(N) / 모임(N)
- 각 탭은 기존 검색 로직 재사용 (getNotes, getUserBooks, searchGroups)
- 커맨드 팔레트(Cmd+K) 연동 고려

관련 파일: app/(main)/search/page.tsx (현재 리다이렉트만), 신규 SearchResultsPage 컴포넌트
