## 1. Executive Summary

ReadTree는 3단계 구독 티어(free/reader/reader_master)를 제거하고 **무료 한도 + 포인트 소비** 모델로 전환하였습니다.
본 문서는 경제적 관점과 마케팅 관점에서 포인트 가격 체계를 분석하고, 유사 서비스 벤치마크를 통해 고도화 방향을 제시합니다.

## 4. 경제적 분석

### 4-1. API 원가 vs 포인트 가격

| 기능 | 포인트 비용 | 원화 환산(스탠다드) | API 실원가 | 마진율 |
|------|-----------|-------------------|----------|--------|
| AI 채팅 | 100P | ~279원 | 0.5~3.5원 | 98.7~99.8% |
| OCR 필사 | 80P | ~223원 | ~2원 | 99.1% |
| AI 리포트 | 150P | ~419원 | 1.5~49원 | 88.3~99.6% |

> API 비용은 매우 저렴하나, 서버 인프라/개발/운영 비용과 큐레이션된 프롬프트/UX 가치를 포함하면 현재 가격은 적절합니다.

### 4-2. 가격 심리학 분석

**앵커링 효과**: 3단 가격 (1,900/3,900/6,900)에서 스탠다드를 highlighted로 설정 → "타협 효과"로 중간 옵션 선택 유도 ✅

**단위 효과**: "100P/회" 표기는 적절한 디커플링 수준. 게임의 공격적인 소액 단위보다는 독서 앱에 맞는 신뢰감 확보

**가격대 적합성**: ₩3,900은 Apple 인앱결제 티어 3과 일치, 한국 소비자 소액결제 심리적 허들(~5,000원) 이내

### 4-3. Freemium 전환율 벤치마크

| 카테고리 | 전환율 |
|---------|--------|
| SaaS 전체 Freemium | 2~5% (일반), 6~8% (상위) |
| EdTech | 5~8% |
| 독서/교육 앱 | 3~5% (예상) |
| 무료 체험형 | 8~12% |

## 5. 핵심 개선 제안

### 5-1. 즉시 적용 (P0)

| 항목 | 현재 | 제안 | 근거 |
|------|------|------|------|
| 첫 충전 보너스 | 없음 | **2배 보너스 (1회)** | 마진 96%+ 유지, 첫 구매 전환율 극대화 |
| 프리미엄 보너스율 | 16.7% | **25~30%** | 상위 패키지 업셀링 유도 |
| 한도 도달 UX | 단순 에러 | **Gain-framing 모달** | 전환율 2~3x (contextual paywall 12% 벤치마크) |

### 5-2. 단기 (P1)

| 항목 | 제안 | 예상 효과 |
|------|------|----------|
| 가입 보너스 분할 | 200P 즉시 + 100P 첫 활동 | 첫 활동 전환율 향상 |
| 친구 초대 양면 보상 | 초대자 500P + 피초대자 500P | 사용자 획득 2~3x |
| 에스컬레이팅 일일 보상 | 스트릭에 따라 8P→18P | DAU 40~60% 증가 |
| 스트릭 마일스톤 확장 | 3개→7개 (3/7/14/21/30/60/100일) | 30일 이탈률 35% 감소 |

### 5-3. 중장기 (P2~P3)

| 항목 | 제안 | 예상 효과 |
|------|------|----------|
| 가변 보상 ("행운의 열매") | 10~25% 확률 랜덤 보너스 | 참여 20~30% 증가 |
| 시즌 이벤트 프로모션 | 연간 7회 이벤트 캘린더 | 매출 시즌 피크 |
| 포인트 정기충전 패스 | ₩4,900~14,900/월 | 안정적 MRR 확보 |
| 포인트 소비처 확장 | AI 추천/요약/토론 가이드 | LTV 증가 |
| B2B 기업 독서 프로그램 | ₩50,000~200,000/월 | 신규 수익원 |
