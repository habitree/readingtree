🧠 심리학 이론 기반 분석
🔌 Hooked Model (Nir Eyal)
🔔
Trigger → Action → Variable Reward → Investment

습관 형성의 4단계 순환. 빈도가 습관 형성의 1순위 요인. 현재 daily_first_activity(8P)가 매일 접속을 유도하는 올바른 설계.

문제: Variable Reward(가변 보상)가 부재. 모든 보상이 고정 포인트 → 예측 가능 → 도파민 감소.
해결: "행운의 열매" 랜덤 보너스 (10~25% 확률, 20~200P)
📈 Endowed Progress Effect
🏆
Nunes & Dreze (2006) 세차장 실험

미리 진행률이 부여된 그룹: 34% 완료
빈 카드 그룹: 19% 완료 (1.8배 차이)

적용: 온보딩 체크리스트 5단계, 가입 시 1단계 자동 완료 = 20% 시작

😱 Loss Aversion (손실 회피)
💸
Kahneman & Tversky - Prospect Theory (1979)

손실의 고통 = 동일한 이득의 기쁨 × 2배

3가지 활용 경로:
1. 포인트 소진 경험 → 충전 동기
2. 스트릭 손실 공포 → 재방문 동기
3. 손실 프레임 알림 → 전환율 2.3배 상승

Duolingo: Streak Freeze 도입 → 이탈률 21% 감소. 유연성이 참여를 오히려 증가시킴.
⏱ Zeigarnik Effect (미완성 효과)
📋
Bluma Zeigarnik (1927)

미완성 과제는 완성 과제보다 기억에 2배 오래 남음

벤치마크 (Userpilot 2025):
- 3단계 체크리스트 완료율: 72%
- 7단계 체크리스트 완료율: 16%
- "20% 진행" 표시 시 완료율 +82%
→ 3~4단계가 최적

⭐ Peak-End Rule
🎯
Daniel Kahneman

경험 평가 = 최고점(Peak) + 마지막(End)

- 참가자 70%가 Peak+End로 전체 경험 판단
- 첫 3일 내 70~80% 이탈
- 첫 세션 목표 달성 시 복귀율 3배

적용: 첫 AI 채팅 = Peak Moment
첫 응답에 Sonnet 모델로 고품질 인사이트 제공

🎓 Self-Determination Theory
💪
Deci & Ryan (2000) - 3대 기본 심리 욕구

자율성: 독서 목표 자유 설정, AI 사용처 선택 ✅
유능감: 레벨 시스템(10단계), 스트릭, 포인트 피드백 ✅
관계성: 독서 모임 기능 🟡 (온보딩에서 유도 약함)

⚠ 주의: 외재적 보상(포인트)이 내재적 동기(독서) 잠식 위험

🎲 Variable Ratio Reinforcement (가변 비율 강화)
🎰
B.F. Skinner - 강화 스케줄 비교

가변 비율 강화가 모든 강화 스케줄 중 최고 반응률과 최고 소거 저항성

Instagram/TikTok의 피드 새로고침이 대표적 사례. 다음 보상이 언제 올지 모르기 때문에 지속 참여.
