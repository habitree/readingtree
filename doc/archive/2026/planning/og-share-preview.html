기술 구현 (v2 — Habitree 브랜딩)
• OG 이미지: next/og ImageResponse (Satori) 서버사이드 동적 생성
• 공통 모듈: lib/og/constants.ts (브랜드 상수) + lib/og/utils.ts (유틸) + lib/og/components.tsx (공통 JSX)
• 배경: 라이트 크림 테마 (#F5F2ED), 포레스트 그린 악센트 (#1d6b4d)
• 텍스트 잘림 방지: 본문 100자, 책제목 30자, 서재명 20자, 인사이트 100자, OG title 25자
• 외부 이미지: prefetchImageAsDataUri()로 base64 변환 → Satori 안정성 확보
• 폰트: NotoSansKR-SemiBold (로컬 → GitHub CDN 폴백)
• 카카오 SDK: v2.7.4 lazy load, 노트만 sendDefault (나머지 OG 자동 파싱)
• 브랜딩: icon.png 로고 이미지 + "Habitree" + "읽는 습관이 자라는 곳" + habitree.app
