통합 기록 피드 — 흩어진 기록이 한 곳에 모입니다

시간 기록·진행율 메모·스탬프·자유 상세가 서로 다른 화면에 흩어져 있던 것을, “내 기록(/notes)”의 “전체” 탭 하나로 모았습니다. 입력 경로는 그대로지만 모이는 곳은 한 곳, 편집도 한 곳입니다. 저장 구조는 그대로(마이그레이션 0)이며 읽기 시점에만 합칩니다.

1 무엇이 달라졌나 — 전 / 후

같은 맥락의 기록이 다른 테이블·다른 화면에 갈라져 있던 문제를 해소

전 (분리)

  • 진행율 슬라이더 메모 → notes → /notes에만 노출
  • 시간세션·스탬프 → reading_logs → 책 시간탭·독서속도·/stamps에 흩어짐
  • 독립 시간세션은 “내 기록”에 아예 안 보임
  • “내가 입력한 게 이곳저곳 나눠져 있다”는 인식

후 (통합)

  • 두 테이블을 읽기 시점에 머지 → /notes 전체 탭 = 모이는 한 곳
  • 같은 날·같은 책의 시간·진행·사진이 한 그룹에 나란히
  • 어떤 카드든 같은 시트에서 편집 → 한 곳에서 수정
  • 저장은 그대로 — 마이그레이션 0, 롤백 1줄

2 통합 피드 화면 — /notes 전체 탭

탭/검색/헤더는 그대로 재사용. “전체” 탭 list 뷰에서만 피드로 승격.

  • 그룹 헤더: “오늘 / 어제 / N월 N일 · 책제목” (KST 기준)
  • 정렬·페이지네이션: 최신순, created_at keyset “더 보기”(offset 미사용 → 누락/중복 없음)
  • 중복 제거: 세션에 달린 상세기록은 세션 카드 하위로 접어 한 세션 = 카드 1개
  • 다른 뷰로 전환: 타임라인/책별/검색은 기존 notes 화면으로 자연 폴백

4 한 곳에서 편집 — “시간만 → 나중에 채우기”

카드 탭 → 종류에 맞는 편집으로 자동 분기. 시간만 기록한 뒤 페이지·메모·사진을 더하면 같은 카드가 그 자리에서 갱신.

시간만 카드 탭 → 사진 추가 시트(attach) → 페이지·메모·사진 입력 → 같은 카드 갱신
  • 시간세션/스탬프 → 기존 RecordSheet 사진 추가(attach) 시트(이미 책 상세·독서속도에서 쓰던 그 시트)
  • 진행율·자유 상세 → 기록 편집 페이지(/notes/[id]/edit)
  • 포인트 추가 적립 없음(편집은 기존 저장 경로 재사용)

5 “진행” 탭 정리 — 분리감 제거

진행율 기록이 전체 피드의 1차 카드가 되면서 전용 탭이 중복이 됨.

  • 내 기록 탭에서 “진행” 탭 제거 — 진행 기록은 전체 피드에서 다른 기록과 함께 보임
  • 기존 링크/북마크 /notes?tab=progress 는 하위호환 유지(서버에서 계속 동작)
  • 책 상세·독서 속도·스탬프 화면은 역할 그대로 — 스코프/분석/컬렉션 전문 뷰
남은 정리(선택): 진행율 기록을 reading_logs로 합치는 데이터 모델 단일화는 여정·포인트 회귀 위험이 있어 별도 게이트로 보류. 현재는 표시·편집만 통합.
