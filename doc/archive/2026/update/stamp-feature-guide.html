3 3-tap 사용 흐름

진입 → 사진 → 페이지 → 시간 → 저장

  1. 진입점 탭 — 모바일 FAB(+) 또는 사이드바 "스탬프" 이어읽기 책이 자동으로 선택됨 (useContinueReading)
  2. 사진 추가 (선택) — 카메라 또는 앨범에서 1장 사진 없이도 OK. 책 표지 그라데이션으로 fallback
  3. 읽은 페이지 입력 — 시작은 직전 기록에서 자동 승계 +5 / +10 / +20 / +30 빠른 증감 칩 + 직접 입력
  4. 읽은 시간 선택 — 10/15/25/30/45/60/90분 프리셋 음악 타이머에서 진입 시 자동 prefill
  5. "스탬프 찍기" — 라이브 미리보기 확인 후 저장 +P 포인트 적립 + user_books.current_page 자동 동기화

6 데이터 흐름 요약

DB · Server Actions · 진입점

📊 DB reading_logs 테이블
　 + image_url (TEXT, nullable)
　 + start_page (INT, 자동승계)
　 + end_page (INT, page_number 미러링)
　 + pace_seconds_per_page (NUMERIC, GENERATED ALWAYS STORED)

⚡ Server Actions app/actions/progress.ts
　 createReadingStamp() → INSERT + updateBookProgress + earnPoints
　 getReadingStamps() → image_url IS NOT NULL 필터 + cursor 페이징
　 getLastEndPage() → start_page 자동승계용

🎨 UI components/stamps/
　 StampCaptureSheet → 입력 시트
　 StampPreviewCard → 라이브 미리보기
　 StampCard / StampCollectionGrid → 컬렉션
　 StampShareButton → html2canvas 1080x1080 PNG

🪝 Hook hooks/use-stamp-capture.ts
　 useStampCaptureStore (zustand) — open / openWithBook / openWithTimer

7 직접 확인 체크리스트

로그인 후 아래 흐름을 순서대로 시도해보세요

  1. 홈 → 모바일 퀵액션 "스탬프" 탭 스탬프 시트가 하단에서 슬라이드 업되는지 확인
  2. 사진 → 카메라 또는 앨범 미리보기 카드에 사진이 즉시 반영되는지 확인 (백그라운드 업로드)
  3. +10p 칩 탭 end_page 가 자동 증가하고 distance 숫자가 라이브 변화하는지 확인
  4. 30분 프리셋 선택 time과 pace 가 라이브 계산되는지 확인
  5. "스탬프 찍기" 탭 토스트 + "+P 적립" 표시, /stamps 와 책 상세 탭에 즉시 반영
  6. 음악 타이머 → 25분 측정 → 종료 완료 다이얼로그의 "스탬프 찍기" 메인 CTA로 진입 시 시간 자동 prefill
