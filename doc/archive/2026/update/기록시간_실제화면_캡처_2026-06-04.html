탭 위에 시간·진행률·여정 요약 스트립

화면 상단의 3색 카드가 신규 요소입니다 — ⏱ 독서시간 · 📊 진행률(바 포함) · 🧭 여정(회독·기록 수). 그 아래 "독서 시간 / 기록 / 여정" 탭이 상세입니다.

이 캡처는 게스트(샘플)라 ⏱ 독서시간이 —로 보이지만, 📊 진행률 100% · 🧭 1회독 · 기록 수는 실제 값으로 렌더됩니다. 로그인 사용자에겐 ⏱에도 누적 시간이 표시됩니다.

컴포넌트: components/books/reading-overview-panel.tsx · 진행률은 공용 computeProgressPercent(A5) 사용 → 다른 화면과 정합.

기록 카드에 ⏱ 독서시간 + "독후감" 항목

• C6: 세션과 연결된 기록의 메타줄에 ⏱ 독서시간 배지(캡처 예: "인용구 · p.120 · 10시간 1분")
• C9: 독후감 기록은 "독후감" 라벨로 구분 표시
이번 캡처 중 버그 발견·수정. C6 배지를 getTimeline에 넣었지만 /notes는 실제로 searchNotes(로그인)·getSampleAllNotes(게스트)를 사용 → 배지가 안 떴습니다. 두 함수에 세션 조인을 추가해 수정 완료(캡처로 검증).

"10시간 1분"은 데모 세션(36100초) 기준이라 큰 값입니다 — 실제 사용 시 세션 시간만큼 표시됩니다.

통계 페이지의 연속 기록일(스트릭)·독서 통계·월간 결산 섹션입니다. 이번 개편으로 스트릭 계산을 한 곳(lib/utils/streak.ts)으로 통일해, 홈 히어로·통계·월간 결산이 같은 값을 보여줍니다(B3-2).

게스트 캡처 불가
(독서시간 조회는 로그인 필요)

왜 캡처가 안 되나

독서 페이스(C7)와 책 상세의 ⏱ 시간 값은 getReadingTimeStats로 세션을 조회하는데, 이 함수는 비로그인(게스트)에서 차단됩니다. 따라서 로컬 게스트 캡처로는 빈 상태만 보입니다.

구현은 완료되어 로그인 사용자의 독서 시간 탭에서 "페이지당 평균 · 읽은 분량 · 남은 예상시간" 카드가 표시됩니다. 정확한 모양은 함께 제공한 기록시간_UI변경_가이드_2026-06-04.html의 충실 목업을 참고하세요.
