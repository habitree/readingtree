## 1. 로드맵 개요

```
Phase 0 (Quick Wins)    ──  1~2일   ── Empty State / 온보딩 즉시 개선
Phase 1 (Core Cold Start) ── 3~5일   ── 인기 도서 / 검색 / 위시리스트
Phase 2 (Engagement)     ──  1주    ── 소셜 프루프 / 위시리스트 뷰 / 알림
Phase 3 (Retention)      ── 1~2주   ── 챌린지 / 개인화 / 리텐션 알림
Phase 4 (Growth)         ── 장기    ── SEO / 공유 / 레퍼럴
```

**DB 마이그레이션:**
```sql
-- migration-YYYYMMDD__books__popular_books_rpc.sql
CREATE OR REPLACE FUNCTION get_popular_books(limit_count INT DEFAULT 12)
RETURNS TABLE (
  book_id UUID,
  title TEXT,
  author TEXT,
  cover_image_url TEXT,
  reader_count BIGINT
)
LANGUAGE sql SECURITY DEFINER STABLE
AS $$
  SELECT
    b.id AS book_id,
    b.title,
    b.author,
    b.cover_image_url,
    COUNT(ub.id) AS reader_count
  FROM books b
  JOIN user_books ub ON ub.book_id = b.id
  GROUP BY b.id
  HAVING COUNT(ub.id) >= 3
  ORDER BY COUNT(ub.id) DESC
  LIMIT limit_count;
$$;
```

**예상 소요**: 7~8시간 (1~2일)
