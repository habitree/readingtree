## 우선순위 매트릭스

```
높은 영향 ↑
           │  [AI 책 추천]     [테스트 환경]
           │  [기록 검색]      [에러 처리]
           │
           │  [소셜 기능]      [코드 정리]
           │  [유료화]         [문서화]
낮은 영향 ↓
           ←───────────────────────────→
           낮은 노력          높은 노력
```

**권장 순서**:
1. 낮은 노력 + 높은 영향 → 먼저 수행
2. 높은 노력 + 높은 영향 → 계획적 수행
3. 낮은 노력 + 낮은 영향 → 여유 시 수행
4. 높은 노력 + 낮은 영향 → 후순위
