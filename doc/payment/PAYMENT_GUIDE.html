2. 결제 플로우

1. 충전하기 클릭 → 2. 서버: 주문 생성 (pending) → 3. 토스 SDK: 결제창 오픈 → 4. 사용자: 결제 완료 → 5. /payment/success 리다이렉트 → 6. POST /api/payment/confirm → 7. 토스 승인 API 호출 → 8. 포인트 충전 + 성공 화면

5. 보안 핵심 사항

  • 금액 위변조 검증: DB의 주문 금액과 클라이언트 전달 금액을 비교, 불일치 시 즉시 거부
  • 인증 필수: 모든 결제 API는 Supabase auth.getUser()로 사용자 확인
  • Rate Limiting: 결제 승인 API는 분당 10회 제한
  • 시크릿 키 보호: TOSS_SECRET_KEY는 서버에서만 사용 (NEXT_PUBLIC 접두사 없음)
  • RLS 적용: 본인 주문만 조회/수정 가능, 관리자만 전체 조회
  • 감사 로그: 모든 결제 이벤트를 payment_history에 기록
  • 중복 결제 방지: 이미 confirmed된 주문은 재처리 거부 (409)
  • 주문 만료: 10분 초과 pending 주문은 자동 expired 처리
