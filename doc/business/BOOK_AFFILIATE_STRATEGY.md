# 도서 구매 제휴(Affiliate) 수익 전략

> 작성: 2026-04-10 | Habitree ReadingTree

---

## 1. 개요

Habitree 독서 앱 사용자에게 **책 구매 버튼**을 제공하여 제휴(affiliate) 수수료 기반 수익을 창출한다.
한국 도서정가제(정가의 15% 이내 할인) 환경에서 현실적 수익 모델을 구축하는 것이 핵심.

---

## 2. 플랫폼별 비교

| 플랫폼 | 도서 수수료 | 쿠키 기간 | API | 도서 메타데이터 | 정산 | 추천도 |
|--------|:---------:|:--------:|:---:|:------------:|:----:|:-----:|
| **쿠팡 파트너스** | 3% | 24시간 | REST API | ★★★ | 현금 | **1순위** |
| **알라딘 TTB** | ~1% (적립금 최대10%) | 7일 | Open API | ★★★★★ | 적립금/현금 | **2순위** |
| **YES24** | 1~2% | 미확인 | 제한적 | ★★★ | 미확인 | 보류 |
| **교보문고** | 미운영 | - | 없음 | ★★ | - | 미적용 |
| **네이버** | 없음 (검색만) | - | 검색 API | ★★★★ | - | 데이터만 |
| **Amazon** | 4.5% | 24시간 | PA-API 5.0 | ★★★★★ | 현금 | 글로벌 확장 시 |

## 3. 추천 전략: 듀얼 연동

### 1순위 — 쿠팡 파트너스 (주 수익)
- **수수료 3%** + 크로스 카테고리 효과 (사용자가 다른 상품 구매해도 수수료)
- API로 ISBN 기반 딥링크 자동 생성
- 한국 최대 이커머스 → 가장 높은 전환율

### 2순위 — 알라딘 TTB (도서 데이터 + 보조 수익)
- **도서 전문 API** — ISBN 기반 정확한 메타데이터 (표지, 가격, 목차)
- 쿠키 7일로 전환 기간 여유
- 적립금 최대 10% (현금 전환 가능)

### 사용자 경험
```
책 상세 페이지 → "구매하기" 바텀시트
  ├─ 🟠 쿠팡에서 구매 (로켓배송) → 쿠팡 파트너스 딥링크
  ├─ 📚 알라딘에서 구매 → 알라딘 TTB 링크
  └─ 📖 최저가 비교 (추후)
```

## 4. 최적 구매 제안 시점 (전환율 순)

| 순위 | 시점 | 예상 CTR | 구현 |
|:---:|------|:-------:|------|
| 1 | "읽고 싶어요" 등록 직후 | 8~15% | 토스트/모달 |
| 2 | 친구/그룹원 리뷰 작성 시 | 5~10% | 피드 내 CTA |
| 3 | 완독 후 같은 저자 추천 | 3~7% | 추천 카드 |
| 4 | 독서 목표 설정 시 | 2~5% | 넛지 알림 |
| 5 | 독서 중 (비추천) | <1% | - |

## 5. 현재 시스템 분석

### 활용 가능한 기존 데이터
- `books.isbn` — ISBN 저장됨 → 서점 링크 자동 생성 가능
- `books.external_link` — 네이버 링크 필드 존재하나 미사용
- `lib/api/naver.ts` — 네이버 API 응답에 `link` 필드 있으나 변환 시 누락

### 필요한 변경
1. `transformNaverBookItem()`에서 `link` 필드 추출 → `external_link`에 저장
2. ISBN 기반 쿠팡/알라딘 딥링크 생성 유틸리티
3. 책 상세 페이지에 "구매하기" 버튼 UI
4. 제휴 링크 클릭 추적 (analytics)

## 6. 수익 시뮬레이션

### 보수적 시나리오 (쿠팡 3% 기준)

| 단계 | MAU | 구매 전환율 | 월 구매건 | 평균가 | 월 수익 |
|------|:---:|:---------:|:-------:|:-----:|:------:|
| 초기 | 1,000 | 2% | 20 | ₩15,000 | **₩9,000** |
| 성장기 | 10,000 | 3% | 300 | ₩15,000 | **₩135,000** |
| 안정기 | 50,000 | 5% | 2,500 | ₩15,000 | **₩1,125,000** |
| 목표 | 100,000 | 5% | 5,000 | ₩15,000 | **₩2,250,000** |

### 낙관적 시나리오 (쿠팡 3% + 알라딘 5% 병행)

| 단계 | MAU | 월 수익 (쿠팡) | 월 수익 (알라딘) | 합계 |
|------|:---:|:------------:|:--------------:|:----:|
| 성장기 | 10,000 | ₩135,000 | ₩112,500 | **₩247,500** |
| 안정기 | 50,000 | ₩1,125,000 | ₩562,500 | **₩1,687,500** |

> 도서정가제 환경에서 제휴 수익만으로는 한계. **AI 리포트 프리미엄 구독 + 제휴 수익** 병행이 현실적.

## 8. 구현 로드맵

### Phase 1 — MVP (1~2주)
- ISBN 기반 쿠팡 파트너스 딥링크 생성
- 책 상세 페이지 "구매하기" 버튼

- 클릭 추적 기본 analytics

- 알라딘 TTB API 연동
- 바텀시트 UI (서점 선택)
- 가격 비교 표시

### Phase 3 — 최적화 (지속)
- 구매 넛지 타이밍 최적화
- A/B 테스트 (버튼 위치, 문구)
- 관리자 대시보드 (전환율, 수익)
- 개인화 추천 연계
