## 2. 상품 라인업 (구독 중심 + 탑업 보조)

> **원칙**: 구독이 메인 수익(MRR), 포인트 탑업은 비구독자/보조 수단

### 2-1. 구독 플랜 (신규)

| | 독서가 (Reader) | 독서마스터 (Master) |
|--|:--:|:--:|
| **가격 (월)** | ₩4,900 | ₩9,900 |
| **가격 (연)** | ₩49,000 (₩4,083/월, 17%↓) | ₩99,000 (₩8,250/월, 17%↓) + 2,000P |
| **AI 채팅** | 50회/월 | 무제한 |
| **OCR** | 20회/월 | 무제한 |
| **AI 리포트** | 3회/월 | 무제한 |
| **월 보너스P** | 200P | 500P |
| **모임 생성** | 10개 | 무제한 |
| **노트 작성** | 무제한 | 무제한 |
| **한도 초과 시** | 포인트로 추가 사용 (기존과 동일) | 해당 없음 |
| **Abuse 방지** | - | 일일 soft cap: 채팅 200회, OCR 100회 |
| **타겟** | 일반 활성 유저 | 헤비유저 |

## 7. 마이그레이션 전략

### 7-1. 롤아웃 Phase

```
Phase 0: 구독 출시 (D-day)
  - 구독 2종 + 미니 탑업 추가
  - 스탠다드/프리미엄은 "레거시" 표시, 결제 페이지 하단 이동
  - 기존 구매자에게 구독 전환 배너 노출

Phase 1: 출시 후 1개월
  - 전환율 데이터 확인
  - 스탠다드/프리미엄 결제 페이지에서 제거 (직접 URL로만 접근)

Phase 2: 출시 후 3개월
  - 스탠다드/프리미엄 완전 제거
  - 최종 상품: 구독 2종 + 탑업 2종
```

### 7-2. 기존 사용자 전환 인센티브

| 기존 행동 | 전환 제안 | 인센티브 |
|----------|----------|---------|
| 프리미엄 매달 충전 | 독서가 (₩2,000/월 절약) | 첫 달 50% 할인 (₩2,450) |
| 스탠다드 매달 충전 | 독서가 (₩1,000 추가에 5배 혜택) | 첫 달 ₩3,900 (스탠다드 가격) |
| 라이트 가끔 충전 | 유지 (탑업으로 계속 사용) | - |
| 충전 경험 없음 | 미니 ₩990 제안 | 첫충전 2배 보너스 유지 |

### 7-3. 전환 유도 (Nudge) 설계

| 시점 | 액션 | 목표 |
|------|------|------|
| 무료 한도 80% 소진 | "이번 달 AI 8/10회 사용. 독서가면 50회!" | 구독 전환 |
| 포인트 탑업 2회 이상 | "매달 충전보다 독서가가 ₩X 절약!" | 구독 전환 |
| 독서가 한도 90% 소진 | "독서마스터로 업그레이드하면 무제한!" | 업그레이드 |
| 구독자 포인트 0 근접 | 미니(₩990) 탑업 제안 | 추가 매출 |

### 7-4. 구독자 + 포인트 상호작용 규칙

| 질문 | 답 |
|------|-----|
| 구독자도 포인트 충전 가능? | O (미니/라이트) |
| 구독자 포인트 용도? | 레벨업, 향후 기프트/프리미엄 기능 |
| 독서가 한도 초과 시? | 포인트로 추가 사용 (40P/회, 기존과 동일) |
| 구독 중간 해지? | 해당 월 말까지 혜택 유지, 잔여 보너스P 소멸 안 함 |
| 구독 갱신 방식? | 별도 결제 (포인트 차감 아님) |
