## 1. 수익 구조 현황

### 유일한 수익원: 포인트 충전

ReadTree는 구독 모델을 제거하고 **무료 한도 + 포인트 소비** 모델을 채택.
사용자는 활동으로 포인트를 적립하거나, 유료 충전으로 포인트를 구매하여 AI 기능을 이용.

| 패키지 | 가격 | 총 포인트 | P당 원가 | 결제 수수료(2.5%) | 순수익 |
|--------|------|----------|---------|-----------------|--------|
| 라이트 | ₩1,900 | 500P | 3.80원 | 47원 | 1,853원 |
| 스탠다드 | ₩3,900 | 1,400P | 2.79원 | 97원 | 3,803원 |
| 프리미엄 | ₩6,900 | 3,800P | 1.82원 | 172원 | 6,728원 |

### 비용 구조

| 항목 | 월간 비용 | 비고 |
|------|----------|------|
| Gemini API | ~0.5~2원/요청 | 현재 주력 AI 모델 |
| GPT-4o-mini (OCR) | ~2.7원/요청 | Gemini 전환 검토 중 |
| Cloud Run OCR | 무료 한도 내 | 월 200만건 vCPU-second 무료 |
| Supabase | 0원 | Free 플랜 |
| Vercel | 0원 | Hobby 플랜 |
| Naver/알라딘/국중도 API | 0원 | 무료 API |
| **합계 (100명)** | **~86,000원** | API 25K + 기타 |
| **합계 (500명)** | **~181,000원** | - |
| **합계 (1,000명)** | **~320,000원** | - |

## 4. 포인트 인플레이션 리스크

### 활발 사용자의 포인트 축적

| 사용자 유형 | 일 적립 | 월 적립 | AI 추가 사용 가능 횟수 |
|------------|--------|--------|---------------------|
| 캐주얼 (43P/일) | 43P | 1,290P | AI 채팅 32회, OCR 52회 |
| 일반 (80P/일) | 80P | 2,400P | AI 채팅 60회, OCR 96회 |
| 활발 (147P/일) | 147P | 4,410P | AI 채팅 110회, OCR 176회 |

### 리스크 평가

**현재 무료 한도가 브레이크 역할을 하고 있음**:
- AI 채팅 10회/월 → 초과 시 포인트 소비 시작
- 활발 유저도 무료 한도 + 적립 포인트로 월 120회 AI 채팅 가능
- 이 수준은 서비스 가치 체험에 충분하며, 비용은 120회 × 0.5원 = 60원/월

**결론**: 포인트 인플레이션 리스크는 **낮음**. 
- 적립으로 인한 AI 사용 증가의 원가 부담은 미미 (최대 ~60원/월)
- 적립 포인트는 유료 전환 없이 AI를 쓰게 하지만, 원가가 극히 낮아 실질 손실 없음
- 오히려 활발 사용자의 리텐션을 높이는 긍정 효과

## 6. 고도화 로드맵

### 6-1. 단기 (0~3개월) — 비용 최적화 & 전환율 향상

| 항목 | 내용 | 예상 효과 |
|------|------|----------|
| **OCR Gemini 전환** | GPT-4o-mini → Gemini 2.0 Flash | 원가 48% 절감 (2.7원→1.4원) |
| **4번째 패키지 추가** | "울트라" ₩14,900 / 8,000P+2,500P | 앵커 효과로 프리미엄 전환율 상승 |
| **에스컬레이팅 일일 보상** | 연속 7일 활동 시 적립 1.5배 | 리텐션 D7 향상 |
| **첫 충전 팝업 타이밍** | 무료 한도 80% 소진 시 팝업 | 전환율 2~3% 상승 기대 |
| **충전 페이지 A/B 테스트** | 패키지 배치, 첫충전 보너스 강조 | 결제 완료율 최적화 |

### 6-2. 중기 (3~6개월) — 수익원 다각화

| 항목 | 내용 | 예상 효과 |
|------|------|----------|
| **구독+포인트 하이브리드** | 월 ₩4,900 구독 → AI 무제한 + 500P/월 | 안정적 MRR 확보 |
| **B2B 독서모임 패키지** | 기업/학교 단체 요금제 (10명+) | 높은 LTV, 낮은 이탈 |
| **AI 리포트 프리미엄** | 고급 분석 리포트 200P | 고가치 상품 추가 |
| **기프트 포인트** | 친구에게 포인트 선물 | 바이럴 효과 + 추가 매출 |

### 6-3. 장기 (6~12개월) — 스케일

| 항목 | 내용 | 예상 효과 |
|------|------|----------|
| **토스페이먼츠 재활성화** | 사업자 등록 후 한국 결제 활성화 | 한국 사용자 전환율 극대화 |
| **연간 구독 옵션** | 연 ₩49,000 (₩4,083/월) | 12개월 Lock-in, 현금흐름 개선 |
| **광고 수익** | 무료 사용자 대상 네이티브 광고 | 추가 수익원 (MAU 5,000+) |
| **제휴 마케팅** | 출판사/서점 제휴 | 컨텐츠 비용 절감 + 수수료 수익 |
