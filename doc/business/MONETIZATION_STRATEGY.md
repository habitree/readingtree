## 1. 현재 무료 버전 분석 및 개선 방향

### 1.1 현재 상태 (As-Is)

현재 코드베이스 기준 무료/유료 한도 (`lib/subscription/gates.ts`):

| 기능 | 무료 (Free) | 프리미엄 (₩4,900/월) | 포인트 소비 |
|------|:-----------:|:--------------------:|:----------:|
| AI 채팅 | 3회/일 | 무제한 | 100P/회 |
| OCR | 3회/일 | 무제한 | 80P/회 |
| AI 리포트 | 2회/월 | 무제한 | 150P/회 |
| 모임 생성 | 2개 | 무제한 | - |
| **노트** | **무제한** | 무제한 | - |
| **서재** | **무제한** | 무제한 | - |
| **그룹 참여** | **무제한** | 무제한 | - |
| **통계** | **전체** | 전체 | - |
| **데이터 내보내기** | **가능** | 가능 | - |

### 1.2 핵심 문제점

| 문제 | 상세 |
|------|------|
| **무료가 너무 충분** | 핵심 기능(책 등록, 노트 무제한, 서재 무제한, 통계)에 제한 없음 |
| **유료 트리거가 AI에만 집중** | AI 3회/일은 일반 사용자에게 충분. 핵심 흐름(기록→검색→공유)에 유료 벽 부재 |
| **포인트로 구독 우회 가능** | 활발한 사용자(~147P/일 적립)는 포인트만으로 AI 초과 사용 → 구독 불필요 |

**근거 데이터** (AI_PRICING_PLAN.md 기준):
- 캐주얼 사용자: ~43P/일 → 2.3일에 AI 1회 추가 사용 가능
- 일반 사용자: ~80P/일 → 1.3일에 AI 1회 추가 사용 가능
- 활발한 사용자: ~147P/일 → 거의 매일 AI 1회 추가 사용 가능

### 1.3 개선 방향: 핵심 기능에 적절한 제한 추가

**원칙**: 무료 사용자가 서비스 가치를 충분히 느낀 뒤(Aha Moment 도달) 자연스럽게 제한에 부딪히도록 설계

- **노트**: 월 30개 제한 → **핵심 전환 트리거** (열심히 기록하는 사용자가 월 중반에 도달)
- **서재**: 3개 제한 → 다독가의 정리 욕구 자극
- **그룹 참여**: 1개 제한 → 커뮤니티 가치 체험 후 확장 동기
- **고급 통계/리포트**: 프리미엄 전용 → 데이터 활용 가치 인식
- **데이터 내보내기**: 프리미엄 전용 → 진지한 사용자의 전환 트리거

## 2. 가격 전략

**전략 근거**: 사용자 기반이 적을 때 복잡한 티어 구조는 혼란만 가중. 단순함이 곧 전환율.

### 2.2 확장 전략 (1,000명+): 3단계 티어

**전환 시점 판단 기준**: 무료→프리미엄 전환율이 5%를 안정적으로 넘기고, 사용자 세그먼트 데이터가 축적된 후

| AI 채팅 | 3회/일 | 15회/일 | 무제한 |
| AI 리포트 | 미제공 | 3회/월 | 무제한 |
| OCR | 3회/일 | 15회/일 | 무제한 |

**가격 심리학 적용**:
- **앵커링**: 가격 페이지에서 ₩6,900 "독서마스터"를 먼저 노출 → ₩3,900 "독서가"가 합리적으로 느껴짐
- **커피 한 잔 프레이밍**: "하루 130원, 커피 한 잔보다 저렴한 독서 성장"
- **추천 배지**: "독서가" 플랜에 "MOST POPULAR" 배지 부착

## 3. AARRR 마케팅 전략

### 3.1 Acquisition (획득) — 목표: 0→1,000명 (3개월)

| 채널 | 전략 | 예상 CAC | 우선순위 |
|------|------|:--------:|:-------:|
| **북스타그램** | 인플루언서 3-5명 협업 (#책스타그램 608만 게시물) | ₩0-3,000 | ★★★ |
| **독서 커뮤니티** | 네이버 카페, 오픈카톡방 직접 홍보 | ₩0 | ★★★ |
| **SEO** | `/share/notes/[id]` 공개 노트 검색 최적화 | ₩0 | ★★☆ |
| **30일 챌린지** | "30일 독서 기록 챌린지" 캠페인 | ₩500/명 | ★★☆ |
| **완독 카드 바이럴** | SNS 공유 카드 → 역유입 (공유 링크에 UTM 포함) | ₩0 | ★★★ |

**핵심 트렌드 활용 — "텍스트힙"**:
- MZ세대 20대 독서율 74.5% (2024 국민독서실태조사)
- 독서가 '힙한 것'으로 자리잡은 트렌드
- 마케팅 메시지: "읽고, 기록하고, 성장하는 나를 보여주세요"

**SEO 전략 상세**:
- 공개 노트 페이지에 OG 메타태그 최적화
- 도서별 노트 모음 페이지 → 책 제목 검색 시 유입
- 블로그 콘텐츠: "독서 노트 작성법", "독서 습관 만들기" 등 키워드

### 3.2 Activation (활성화) — 목표: Aha Moment 도달률 60%+

**Aha Moment 정의**: "첫 노트 작성 → AI 자동 태깅 적용 순간"

| 액션 | 현재 | 개선 |
|------|------|------|
| 온보딩 | 다단계 | "문장 한 줄 입력" → 자동 분류 (3단계→1단계) |
| 첫 행동 유도 | 없음 | 가입 즉시 "좋아하는 책 한 줄 감상" 입력 가이드 |
| 웰컴 포인트 | 300P (구현됨) | AI 채팅 3회 + OCR 3.7회 체험 가능 ✅ |
| AI 체험 | 자발적 | 첫 노트 작성 시 AI 태깅 자동 실행 → "와, 이런 것도 되네!" |

**활성화 퍼널 목표**:
```
가입 → 첫 책 등록 (80%) → 첫 노트 작성 (60%) → AI 태깅 체험 (50%) → Day 1 재방문 (40%)
```

### 3.3 Retention (유지) — 목표: Day 7 잔존율 40%, Day 30 25%+

| 시점 | 전략 | 구현 상태 |
|------|------|:--------:|
| **Day 0** | 환영 보너스 300P | ✅ 구현됨 |
| **Day 1** | 푸시: "어제 읽은 책에서 기억나는 문장이 있나요?" | ⬜ 미구현 |
| **Day 3** | AI 대화 체험 유도: "이 책에 대해 AI와 대화해보세요" | ⬜ 미구현 |
| **Day 7** | 주간 리포트 이메일 (읽은 페이지, 작성 노트 수) | ⬜ 미구현 |
| **Day 14** | 2주 연속 스트릭 축하 + 보너스 50P | ✅ 스트릭 시스템 구현됨 |
| **Day 30** | "30일 기념 프리미엄 7일 무료 체험" 제공 | ⬜ 미구현 |
| **매일** | 일일 미션 (노트 작성, 독서 기록 등) | ✅ 구현됨 |

**리텐션 핵심 메커니즘**:
- **스트릭**: 연속 기록 → 놓치기 싫은 심리 (손실 회피)
- **레벨 시스템**: 10단계 (씨앗→황금숲) → 성장 시각화
- **커뮤니티**: 그룹 독서 → 사회적 책임감

### 3.4 Revenue (수익화) — 목표: 전환율 5-8%

**자연스러운 유료 전환 트리거 (무료 제한 강화 후)**:

| 순위 | 트리거 | 예상 전환율 | 시점 |
|------|--------|:----------:|------|
| 1 | **노트 30개 도달** (월 중반) | 5-8% | 가입 후 2-3주 |
| 2 | AI 채팅 한도 도달 | 3-5% | 매일 |
| 3 | 완독 후 AI 리포트 열람 시도 | 4-6% | 완독 시 |
| 4 | **30일 스트릭 달성** 시 프리미엄 무료체험 제안 | 8-12% | 가입 후 30일 |
| 5 | 서재 3개 초과 시도 | 3-5% | 가입 후 1-2개월 |

**전환 UX 설계**:
```
[무료 한도 도달] → [부드러운 안내 모달]
  ├── "이번 달 노트 30개를 모두 사용했어요!"
  ├── "프리미엄으로 업그레이드하면 무제한으로 기록할 수 있어요"
  ├── [프리미엄 시작하기 ₩4,900/월] (CTA 버튼)
  └── [다음 달까지 기다리기] (부드러운 대안)
```

**절대 하지 말 것**:
- 기존 데이터 접근 차단 (작성한 노트 읽기는 항상 가능)
- 강압적인 팝업/광고
- 포인트로 구매한 기능의 소급 제한

**subscription_tiers**: `free` (₩0), `premium` (₩4,900)
- `features` JSONB: `{ ai_chat_daily: 3, ocr_daily: 5, groups_create: 2 }`

**user_subscriptions**: 1인 1구독, `status`: active/cancelled/expired
