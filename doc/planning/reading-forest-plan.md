# Habitree "나의 독서 숲" 시각화 페이지 기획서

> 작성일: 2026-03-08
> 버전: v1.0 (초안)

---

## 1. 개요

### 1.1 목적
사용자가 읽은 책들을 "나무와 숲"이라는 Habitree 브랜드 메타포로 시각화하여,
**한눈에 독서 여정을 파악**하고 **자연스럽게 자랑(공유)하고 싶어지는** 페이지를 만든다.

### 1.2 핵심 가치
- **직관성**: 복잡한 데이터를 나무/숲으로 단순화하여 인지 부하 최소화
- **성장감**: 책을 읽을수록 나무가 자라고 숲이 울창해지는 시각적 보상
- **공유성**: SNS에 자랑하고 싶은 아름다운 디자인 (Spotify Wrapped + GitHub 잔디)
- **브랜드 일체감**: Habitree = 습관(Habit) + 나무(Tree)

### 1.3 배치 위치
| 위치 | 역할 |
|------|------|
| **서재(Bookshelves) 탭** | "나의 숲" 뷰 모드로 전환 가능 |
| **메인 대시보드** | 미니 숲 위젯 (독서달력 옆 배치) |
| **프로필 페이지** | 방문자에게 보여주는 숲 전경 |
| **독립 페이지** | `/my-forest` 전체 화면 숲 탐험 |

## 2. 핵심 컨셉: 나무 성장 시스템

### 2.1 5단계 나무 성장 모델

| 단계 | 상태 | 진행률 | 시각적 표현 |
|------|------|--------|------------|
| **씨앗** | 책 등록 | 0% | 흙 위의 작은 씨앗 |
| **새싹** | 첫 기록 | 1~15% | 연두색 떡잎 2장 |
| **어린나무** | 읽는 중 | 16~50% | 가느다란 줄기 + 작은 잎 |
| **성장목** | 후반부 | 51~99% | 굵은 줄기 + 풍성한 수관 |
| **완성목** | 완독 | 100% | 열매/꽃이 달린 큰 나무 |

### 2.2 장르별 나무 종류

| 장르 | 나무 | 시각적 특징 |
|------|------|------------|
| 소설/문학 | 벚꽃나무 | 분홍 꽃잎, 감성적 |
| 자기계발 | 소나무 | 곧은 줄기, 사시사철 푸름 |
| 과학/기술 | 은행나무 | 부채꼴 잎, 체계적 |
| 역사/인문 | 느티나무 | 넓은 수관, 깊은 뿌리 |
| 에세이/시 | 단풍나무 | 다채로운 색감 |
| 경제/경영 | 대나무 | 빠른 성장, 곧은 절개 |
| 예술/디자인 | 등나무 | 유연한 곡선, 꽃 덩굴 |

### 2.3 평점 반영 (완독 후)
- 5점: 황금빛 열매
- 4점: 건강한 열매
- 3점: 보통 열매
- 2점 이하: 열매 없이 잎만 무성

## 3. 숲 레이아웃

### 3.1 기본 뷰: 시간순 배치
```
┌─────────────────────────────────────────────┐
│  [시간순]  [장르별]  [크기순]    🔍 검색     │
├─────────────────────────────────────────────┤
│                                             │
│    🌳      🌲                               │
│       🌱        🌳    🌿                    │
│  🌲       🌳         🌱     🌳              │
│       🌿       🌲          🌲               │
│    🌱     🌳        🌳         🌿           │
│                                             │
│  ─── 2026 ──────── 2025 ──────── 2024 ───  │
└─────────────────────────────────────────────┘
```

- 최근 나무가 앞쪽(크게), 과거로 갈수록 뒤쪽(작게)
- Y축 랜덤 오프셋으로 자연스러운 숲 느낌
- 2.5D 아이소메트릭 원근감

### 3.2 밀도 표현
| 독서량 | 숲 상태 | 부가 요소 |
|--------|---------|----------|
| 0~5권 | 빈 들판 | 풀밭, 씨앗 |
| 6~20권 | 작은 숲 | 나무 듬성듬성 |
| 21~50권 | 울창한 숲 | 새/나비 파티클 |
| 51~100권 | 깊은 숲 | 숲길, 시냇물 |
| 100권+ | 태고의 숲 | 안개, 동물 캐릭터 |

### 3.3 필터 뷰
- **장르별 구역**: 소설림, 인문숲, 기술원 등으로 분리
- **크기순**: 가장 큰 나무(긴 책/높은 평점)부터 배치

## 4. 계절/환경 시스템

### 4.1 독서 활동 기반 계절 변화
실제 계절이 아닌 **사용자 활동량**에 따라 숲 분위기 변화:

| 최근 7일 활동 | 숲 상태 | 시각적 표현 |
|-------------|---------|------------|
| 매일 기록 | 한여름 | 짙은 초록, 햇살, 나비/새 |
| 4~6일 | 봄 | 연두색, 꽃잎 날림 |
| 2~3일 | 가을 | 노란/주황 단풍, 낙엽 |
| 1일 | 늦가을 | 갈색, 잎 떨어짐 |
| 0일 | 겨울 | 앙상한 가지, 눈 |

### 4.2 시간대별 라이팅
| 시간 | 분위기 |
|------|--------|
| 06~11시 | 따뜻한 골든 아침 |
| 12~17시 | 밝고 선명한 한낮 |
| 18~20시 | 주황/보라 석양 |
| 21~05시 | 별빛 + 반딧불이 |

### 4.3 특별 효과
- **메모 작성**: 비가 와서 나무에 물을 주는 연출
- **연속 독서**: 스트릭에 비례하여 밝기 증가
- **주간 목표 달성**: 무지개 등장

## 5. 인터랙션 설계

| 동작 | 결과 | 플랫폼 |
|------|------|--------|
| 나무 탭 | 책 정보 팝오버/바텀시트 | 모바일: bottom sheet |
| 핀치 줌 | 조감도 ↔ 개별 나무 | 터치 이벤트 |
| 스와이프 | 시간축 이동 | 가로 스크롤 |
| 더블 탭 | 나무 줌인 + 상세 | 애니메이션 줌 |

### 5.1 조감도 줌 레벨
- **레벨 1 (전체)**: 나무가 점으로 표시, 통계 오버레이
- **레벨 2 (구역)**: 나무 아이콘 보이는 중간 줌
- **레벨 3 (개별)**: 개별 나무 크게 + 상세 정보

## 9. 기술 스택

| 용도 | 기술 | 비고 |
|------|------|------|
| 나무 렌더링 | 순수 SVG | 추가 의존성 없음 |
| 애니메이션 | Framer Motion | 이미 설치됨 |
| 레이아웃 | CSS Grid + Tailwind | 이미 설치됨 |
| 이미지 캡처 | html2canvas → html-to-image | 전환 권장 |
| 줌/패닝 | react-zoom-pan-pinch | 필요시 추가 |

### 9.1 성능 전략
| 책 수 | 전략 |
|--------|------|
| ~100권 | 순수 SVG + Motion, 성능 이슈 없음 |
| 100~300권 | React.memo + IntersectionObserver |
| 300권+ | SVG 단순화 또는 Canvas 전환 검토 |

## 12. 참고 사례 및 출처

### 앱/서비스
- Forest (집중 타이머 + 나무 성장)
- StoryGraph (무드/페이스 그래프, Stats V4)
- Bookly (책별 인포그래픽 자동 생성)
- Spotify Wrapped (바이럴 공유의 교과서)
- GitHub Contribution Graph (잔디밭 동기부여)

### 심리학 원리
- Zeigarnik 효과: 미완료 과제의 인지적 긴장
- Endowed Progress Effect (Nunes & Dreze, 2006)
- Self-Determination Theory (Ryan & Deci, 2000)
- 손실 회피 (Loss Aversion)
- 인지 부하 이론 (Sweller, 1988)
- Progressive Disclosure (NNGroup)
