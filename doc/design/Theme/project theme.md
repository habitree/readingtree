# 🌱 Project Theme Refinement Guide
## 기존 시스템에 「사유의 정원 / 정원사」 테마 적용을 위한 고도화 문서

---

## 0. 문서 목적

이 문서는 이미 구성·개발 중인 독서/지식 관리 시스템에  
**새로운 테마(사유의 정원 / 정원사)를 무리 없이 적용**하기 위한 기준 문서이다.

목표는 다음과 같다.

- 기존 기능, 데이터 구조, 개발 자산을 **최대한 유지**
- 테마를 “디자인 변경”이 아닌 **의미 재정렬**로 적용
- 디자이너, 개발자, AI 프롬프트가 **같은 기준선**을 공유

---

## 1. 최종 테마 선언 (Project-wide Lock)

### 1.1 핵심 테마

> **최소한의 손질만 된 사유의 정원**  
> 사용자는 이 정원을 가꾸는 **정원사**

---

### 1.2 한 문장 정의

이 시스템은  
**사용자의 사고가 자라도록 방해하지 않는 환경을 제공하는  
지적 사유의 정원**이다.

---

### 1.3 이 테마가 의미하는 것

- 시스템은 설명하지 않는다
- 시스템은 앞서지 않는다
- 시스템은 성과를 강요하지 않는다
- 오직 사고가 자랄 수 있는 **공간과 구조**만 제공한다

---

## 2. 적용 원칙 요약 (가장 중요)

### ❌ 하지 말아야 할 것
- 전면 UI 리뉴얼
- 컬러/폰트 교체부터 시작
- 기능 삭제 또는 구조 변경
- “자연 컨셉”을 이유로 한 감성 과잉

### ✅ 반드시 지켜야 할 것
- 기능은 유지, **의미만 재정의**
- 디자인은 추가가 아니라 **절제**
- 변경은 항상 **레이어 단위**로 진행

---

## 3. 기존 기능 → 사유의 정원 메타포 매핑

| 기존 기능 | 기존 인식 | 사유의 정원 관점 재정의 |
|---|---|---|
| 책 추가 | 데이터 입력 | 씨앗 심기 |
| 독서 기록 | 로그 작성 | 물 주기 |
| 메모 / 필사 | 정리 | 가지 성장 |
| 연결 메모 | 링크 | 가지 연결 |
| 통계 | 성과 지표 | 성장의 흔적 |
| 그룹 | 공유 | 숲 확장 |
| AI 요약 | 효율 | 조용한 보조 도구 |

> ⚠️ 기능은 삭제하지 않는다  
> ⚠️ UI 설명과 톤만 변경한다

---

## 4. 디자인 고도화 가이드 (Designer 기준)

### 4.1 디자인 철학

- “잘 디자인된 화면”보다  
  **“아무 일도 하지 않아도 불안하지 않은 화면”**

---

### 4.2 시각적 디자인 원칙

#### 색상 (Color)
- 기존 컬러 팔레트 유지
- 채도와 대비를 **단계적으로 낮춤**
- 강조 색상은 **사용자 행동 이후에만 등장**

#### 타이포그래피 (Typography)
- 신규 폰트 도입 ❌
- 굵기 단계 수 줄이기
- Line-height 및 여백 확대
- 정보 밀도를 낮추는 방향

#### 레이아웃 (Layout)
- 카드 UI 남용 금지
- 한 화면, 하나의 핵심 맥락
- 여백은 기능이다 (비어 있음 허용)

---

### 4.3 우선적으로 “숨길” UI 요소

**1순위**
- KPI / 수치 강조 영역
- 메인 화면의 AI 자동 요약 카드
- 과도한 CTA 버튼

**2순위**
- 설명 과잉 텍스트
- 아이콘 + 텍스트 중복
- 의미 없는 애니메이션

---

## 5. UX 흐름 재정렬 가이드 (개발자 기준)

### 5.1 UX 전환 공식


#### 예시
- ❌ “AI 요약 보기”
- ✅ “이 기록을 다시 바라보기” → 내부에서 AI 도움 제공

---

### 5.2 개발 원칙 (강제)

#### 필수
- 모든 기록에 시간성(Time) 포함
- 기록은 수정 가능하되 흔적은 유지
- 관계(Relation)는 느슨하게 유지

#### 금지
- “오늘의 추천”
- 성과 중심 대시보드 우선 노출
- AI 자동 생성 결과를 메인 정보로 노출

---

## 6. AI / 프롬프트 레이어 고도화

### 6.1 AI 페르소나 선언

AI는 사용자의 사고를 대신하지 않는다.  
AI는 정원사보다 앞서지 않는다.

AI의 역할은 다음으로 제한한다.

- 기록 간의 연결 가능성 제시
- 반복되는 사고 패턴 관찰
- 비어 있는 지점을 질문으로 남기기

## 7. 테마 적용 완료 판단 기준

아래 3가지가 충족되면  
테마 전환은 “성공”으로 간주한다.

- [ ] 기능 설명에서 ‘성과 / 효율 / 요약’이라는 단어가 사라졌다
- [ ] AI가 말수가 줄었다
- [ ] 화면을 가만히 보고 있어도 불안하지 않다

---

- AI 프롬프트 설계 시 **페르소나 고정 기준**
