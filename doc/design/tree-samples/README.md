# tree-samples — 포인트 트리 이미지 생성기

포인트 레벨 트리 이미지(`public/images/trees/`)를 생성·재현하는 작업 폴더.

- **`gen_trees_v5.py`** — 정식(현행) 생성기. 단독 실행, 외부 의존 없음. 색감/형태/시그니처 조정은 이 파일에서.
- **`reference/`** — 현행 v5 레벨 오버뷰 미리보기.
- **`_archive/`** — 구버전 생성기(v1·v3·v4)와 초기 샘플(보존용, 참조만).

생성·교체 절차와 레벨 매핑 기준은 상위 문서 **[../tree-image-system.md](../tree-image-system.md)** 참조.
