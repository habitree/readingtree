Active Reader

독서인

📵
Non-Reader

비독서인

바빠서 책을 읽지 않는 직장인, 32세 마케터. 자기계발 욕구는 있지만 실행이 어렵다.

🌱
Aspiring Reader

예비독서인

책 읽고 싶은데 어디서 시작할지 모르는 28세 대학원생. 좋은 큐레이션을 원한다.

🏪

서점인

이해관계자별 대화식 검토

3개 장면에 걸쳐 6개 페르소나가 리포트 공유 기능을 검토한다

SCENE 1

처음 공유 리포트를 보았을 때

카카오톡으로 리포트 링크가 공유됨 — 각자 링크를 열어보는 상황
📚
독서인
와, 이거 내 연간 독서 리포트잖아. 시각적으로 꽤 예쁘게 나왔네. 내가 SF를 이렇게 좋아하는 줄 몰랐는데, AI가 잡아냈어. 근데... 이걸 공유해서 뭘 얻는 거지? 그냥 '나 책 많이 읽었어'를 자랑하는 건가?
📵
비독서인
(링크 열어보며) 어, 이게 뭐야? 독서 리포트? 친구가 올해 책을 28권 읽었다고? 대단하긴 한데... 그래서 나한테 뭘 해달라는 거지? 나보고 읽으라고? 솔직히 이 페이지 10초 보다가 닫았어.
🌱
예비독서인
(천천히 스크롤하며) 오 신기하다. 이 사람이 읽은 책들 제목이 보이네. 《원씽》, 《아주 작은 습관의 힘》... 어, 나도 이 책 읽고 싶었는데. 근데 어디서 사지? 클릭하면 살 수 있나? (눌러보지만 링크가 없음) 아, 아무것도 없네.
🏪
서점인
(업무 중 링크를 봄) 독서 리포트를 공유한다고? 흥미롭네. 이 사람이 읽은 책 목록을 보니 베스트셀러도 있고 독립출판물도 있어. 만약 이 리포트에 '저자 사인본 구매' 링크가 있었다면 우리 가게 트래픽이 됐을 텐데. 근데 지금은 아무 연결도 없어.
📦
유통인
(마케팅 시각으로) 이 기능... 데이터 관점에서 흥미롭네. 특정 책이 몇 번이나 리포트에 등장하는지 알 수 있다면 베스트셀러 예측 지표가 될 수도 있겠어. 근데 지금은 그 데이터가 아예 없고, 공개 피드도 없어. 아쉽다.
✍️
저자
(알림을 통해 발견) 누군가 내 책을 읽고 리포트를 공유했구나. 어떻게 느꼈는지 궁금한데... 리포트에 내 책이 언급된 부분을 찾아보려니 전체를 다 읽어야 해. 독자가 내 책에 대해 뭘 생각하는지 한눈에 보고 싶은데.
SCENE 2

기능의 가능성과 한계 토론

6명이 한 자리에 모여 리포트 공유 기능에 대해 토론하는 상황
🌱
예비독서인
솔직히 말하면, 이 페이지에서 제일 궁금한 건 '저 사람이 읽은 책들 어떻게 사지?'예요. 근데 아무 링크가 없으니까 그냥 구글 검색해야 하잖아요. 독서 리포트가 책 구매로 이어질 수 있는 가장 자연스러운 순간인데, 그걸 놓치고 있어요.
🏪
서점인
맞아요. 독서 리포트는 사실 굉장히 강력한 구매 유발 콘텐츠예요. '이 사람이 읽고 감동받은 책'이라는 맥락이 붙으면 일반 광고보다 훨씬 신뢰도가 높거든요. 근데 지금은 그 가능성을 완전히 날리고 있어요.
📚
독서인
저도 공유하는 입장에서 솔직히 말하면, '와 대단하다'는 반응을 원하긴 해요. (웃음) 근데 그게 다예요. 공유하고 나서 친구가 '나도 이 앱 써보고 싶다'고 하면 뿌듯할 것 같은데, 지금 CTA가 너무 약한 것 같아요. '앱 다운로드' 버튼 하나만 있는데, 비독자한테는 동기부여가 없잖아요.
📵
비독서인
저한테는 솔직히 이 리포트가 '나는 책을 안 읽는 루저야'라는 느낌을 줘요. (웃음) 책 많이 읽는 사람의 자랑처럼 보이거든요. 만약 '당신도 한 달에 책 1권으로 이런 변화를 경험할 수 있어요'라는 메시지가 있었다면 달랐을 것 같아요.
📦
유통인
데이터 관점에서 가장 아쉬운 건 공개 피드가 없다는 거예요. 지금은 공유해도 그 리포트가 어딘가에 쌓이지 않잖아요. 만약 공개 피드가 생기면 '이번 달 가장 많이 읽힌 책', '이 책을 읽은 사람들의 공통점' 같은 집계 데이터가 나올 수 있어요. 출판사 입장에서는 황금 같은 마케팅 인사이트죠.
✍️
저자
저는 독자 피드백을 정말 갈망해요. SNS에서 '이 책 좋아요'라는 댓글은 많은데, 실제로 어떻게 읽었는지, 어떤 챕터가 인상 깊었는지는 잘 몰라요. 만약 AI 리포트에서 내 책이 언급된 내용만 저에게 알림이 간다면... 그건 정말 가치 있는 독자 인사이트가 될 것 같아요.
📚
독서인
그리고 인스타 공유! 지금은 카카오톡만 되는데, 인스타 스토리용 이미지가 있으면 확산력이 엄청 달라질 거예요. 텍스트 리포트를 시각적인 카드로 만들어서 '올해 나의 독서 결산'으로 공유하면 완전 바이럴될 것 같은데.
🌱
예비독서인
맞아요! 연말에 스포티파이 연간 결산처럼요. 독서 버전 '독서 레시피' 같은 거. 그게 있으면 저도 앱 설치할 것 같아요.
SCENE 3

"이런 게 있으면 좋겠다" 아이디어 제안

각자 리포트 공유 기능에 대해 하나씩 원하는 기능을 제안하는 상황
📚
독서인 — 독자 경험 최적화 관점
리포트를 공유할 때 '하이라이트 카드' 기능이 있으면 좋겠어요. 예를 들어, 내가 올해 읽은 책 중 베스트 3를 뽑아서 인스타 스토리 비율(1:1이나 4:5)로 예쁜 이미지 카드를 만들어주는 거예요. 'AI가 분석한 나의 독서 성향' 같은 문구도 자동으로 들어가고요. 지금처럼 링크만 공유하는 것보다 훨씬 임팩트 있을 것 같아요.
📵
비독서인 — 비사용자 유인 관점
저 같은 비독자를 위한 '책 핵심 요약 카드' 기능이 있으면 어때요? 리포트를 보다가 관심 가는 책 제목을 클릭하면, AI가 그 책의 핵심 인사이트를 3문장으로 요약해주는 거예요. '5분 만에 이 책의 핵심 배우기' 같은 느낌으로요. 비독자가 독서에 진입하는 가장 낮은 허들이 될 수 있을 것 같아요.
🌱
예비독서인 — 책 발견 및 구매 관점
리포트에 있는 책마다 구매 링크가 자동으로 달렸으면 해요. ISBN 기반으로 알라딘, 교보문고, 예스24 딥링크가 바로 연결되면 좋겠어요. 리포트 보다가 '오, 이 책 읽고 싶다'는 순간이 오는데, 그 순간 바로 살 수 있어야 하잖아요. 지금은 구글 검색 → 서점 검색 → 구매로 3단계인데, 1단계로 줄일 수 있어요.
🏪
서점인 — 판매 전환 관점
서점 파트너십 기능이요. 특정 지역 독립서점과 연동해서, 리포트에 있는 책들이 해당 서점에 있으면 '가까운 서점에서 보기' 버튼이 뜨는 거예요. 대형 온라인 서점과 달리 독립서점은 큐레이션과 커뮤니티가 강점이잖아요. 독서인과 서점을 연결하는 허브 역할을 Habitree가 할 수 있다고 봐요.
📦
유통인 — 데이터 및 마케팅 관점
공개 리포트 피드와 집계 데이터요. 월간 '이 책이 가장 많이 리포트에 등장했어요' 같은 트렌딩 지표. 출판사가 이 데이터를 구독하면 마케팅 예산을 훨씬 효율적으로 쓸 수 있어요. 또 '이 책을 읽은 사람들이 다음에 읽은 책' 같은 연관 도서 데이터는 추천 알고리즘의 핵심이 될 수 있고요.
✍️
저자 — 창작자 관점
저자 대시보드를 만들어주세요. 내 책이 언제, 얼마나 읽혔는지, 독자들이 AI 리포트에서 내 책에 대해 어떤 말을 했는지 볼 수 있는 곳이요. 지금은 판매량 데이터는 있지만 '어떻게 읽혔는지' 데이터는 전혀 없어요. 저자 입장에서는 인세보다 더 가치 있는 피드백이에요.

도출된 기능 후보 목록

단기·중기·장기로 분류된 14개 기능 후보

단기 Quick Wins · 1~2 sprint 기존 아키텍처에서 빠르게 구현 가능한 기능
QW-1

리포트 하이라이트 카드 생성

리포트 핵심 요소를 인스타그램용 이미지 카드로 생성. 1:1 스퀘어, 4:5 포트레이트, 9:16 스토리 비율 지원.

독서인 바이럴 @vercel/og
QW-2

책 구매 링크 자동 삽입

ISBN 기반으로 알라딘·교보문고·yes24 딥링크 자동 연결. 리포트 내 책 제목 클릭 시 즉시 서점으로 이동.

예비독자 구매 전환 ISBN API
QW-3

공유 리포트 조회수 표시

리포트 공유 시 조회수 카운터 표시 (n명이 읽었어요). view_count 컬럼 추가만으로 구현 가능.

독서인 참여도
QW-4

리포트 이모지 반응 기능

공개 리포트에 이모지 반응 추가 (👏 멋지다, 📚 나도 읽어볼게, 💡 인사이트 얻었어). report_reactions 테이블 신설.

전체 소셜 참여
중기 Mid-term · 1~2 months 새로운 데이터 구조나 기능이 필요한 기능

공개 리포트 피드 (탐색 페이지)

/explore/reports — 공개된 리포트 모아보기. 최신/트렌딩/장르별 필터 지원.

비독자·예비독자 DAU

기술 제약, 개인정보 및 보안, UX 원칙

⚙️ 기술 제약

  • 이미지 생성: 서버사이드 @vercel/og 권장 (클라이언트 html2canvas는 CORS 이슈 가능)
  • 책 구매 링크: ISBN 기반 딥링크는 서점마다 URL 패턴이 다름, 테스트 필요
  • 공개 피드 성능: 페이지네이션 + Supabase RLS 정책 설계 중요
  • AI 요약 캐싱: 동일 책의 요약은 DB에 캐싱하여 API 비용 절감

🔒 개인정보 및 보안

  • 공유 리포트의 독서 노트 포함 여부는 사용자 선택 유지
  • 저자 대시보드는 집계 데이터만 공개, 개별 독자 식별 불가
  • 공개 피드 RLS: is_public = true인 리포트만 노출
  • 신규 테이블 생성 시 RLS 4가지 정책 즉시 적용

✨ UX 원칙

  • 공유 페이지는 비로그인 사용자 최적화 (앱 없어도 가치 있게)
  • CTA는 강요가 아닌 자연스러운 유입 유도
  • 비독자에게는 '부담 없는 독서 시작' 메시지
  • 서점 파트너십 링크는 독립서점 우선 노출로 커뮤니티 가치 유지

결론

이해관계자 분석이 밝혀낸 리포트 공유의 진짜 잠재력

리포트 공유 기능, 어디까지 갈 수 있을까?

현재는 독서인의 자기 표현 도구에 머물고 있지만, 이해관계자 분석을 통해 확인한 것은 이것이다:

  1. 1 예비독자: 가장 직접적인 전환 기회 — 책 발견 → 구매 → 앱 가입 퍼널이 자연스럽게 연결된다
  2. 2 비독자: 바이럴 확산의 핵심 — 리포트를 보고 독서에 관심 갖게 되는 계기가 필요하다
  3. 3 저자/출판사: B2B 수익 모델의 시작점 — 독자 인사이트에 대한 수요가 실재한다
  4. 4 서점: 오프라인-디지털 연결의 새로운 채널 — 독립서점 생태계와 시너지를 낼 수 있다

첫 번째 액션: QW-1 + QW-2

가장 임팩트 있고 빠른 첫 걸음은 하이라이트 카드 생성 (QW-1)과 책 구매 링크 자동 삽입 (QW-2)이다. 두 기능만으로 바이럴 잠재력과 구매 전환 퍼널을 동시에 열 수 있다. 다음 스프린트의 최우선 과제로 제안한다.
