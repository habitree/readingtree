## 주요 컴포넌트

### Provider 모듈 (`lib/ai/providers/`)

각 AI 제공자별 클라이언트와 유틸리티 함수 제공:

| 함수 | 설명 |
|------|------|
| `getXXXClient()` | API 클라이언트 초기화 |
| `callXXX()` | 스트리밍 API 호출 |
| `parseXXXStream()` | 스트림 파싱 |
| `generateWithXXX()` | 단순 텍스트 생성 |
| `summarizeWithXXX()` | 책 요약 전용 |
| `streamXXXChat()` | 편의 함수 (call + parse) |

### Prompt 모듈 (`lib/ai/prompts/`)

| 파일 | 주요 함수 |
|------|----------|
| `chat-prompts.ts` | `generateDynamicSystemPrompt()` - 동적 시스템 프롬프트 생성 |
| | `generateSystemPrompt()` - 레거시 프롬프트 (하위 호환) |
| `summarization-prompts.ts` | 책 요약 프롬프트 템플릿 |

### Server Actions (`app/actions/ai/`)

| 파일 | 주요 기능 |
|------|----------|
| `chat.ts` | 세션 관리, 메시지 저장, 컨텍스트 조회 |
| `settings.ts` | AI 설정 CRUD, 연결 테스트 |
| `persona.ts` | 페르소나 분석, 저장 |
| `summarization.ts` | 책소개 요약 (Naver API + Gemini) |
| `ocr.ts` | 이미지에서 텍스트 추출 |

### 채팅 기능

채팅은 관리자 설정에 따라 **단일 Provider만 사용**합니다.
Provider 장애 시 에러 메시지를 사용자에게 표시합니다.

## 동적 프롬프트 구성

시스템 프롬프트는 관리자 설정과 사용자 컨텍스트를 조합하여 동적으로 생성됩니다:

```
┌─────────────────────────────────────────┐
│           시스템 프롬프트 템플릿          │
│  (관리자가 설정한 기본 프롬프트)          │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│  + 사용자 페르소나 (contextSettings)     │
│    - 독서 속도                          │
│    - 기록 스타일                        │
│    - 활동 시간                          │
│    - 선호 장르                          │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│  + 최근 읽은 책 (최대 5권)               │
│    - 제목, 저자, 상태                    │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│  + 최근 기록 (최대 10개)                 │
│    - 인용구, 메모, 사진 등              │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│  + 독서 목표                            │
│    - 연간 목표, 완독 수, 진행률          │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│         최종 시스템 프롬프트              │
└─────────────────────────────────────────┘
```
