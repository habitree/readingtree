2. Phase 1: 프롬프트 고도화

P0 핵심

기존 약 15줄의 단순 시스템 프롬프트를 6섹션 구조로 전면 재설계했습니다. 관리자 패널에서 편집 가능한 템플릿 기반으로, 런타임에 사용자 컨텍스트가 동적으로 주입됩니다.

시스템 프롬프트 6섹션 구조

구현 위치: types/ai/settings.ts — DEFAULT_AI_SETTINGS.systemPromptTemplate

❶ 핵심 정체성 & AI 투명성
  • AI임을 투명하게 밝히며, 전문 상담사가 아닌 독서 보조 도구로 포지셔닝
  • 독서와 관련된 대화에만 집중
  • 사용자가 스스로 생각하고 발견하도록 돕는 것이 핵심 목표
  • 친근하고 따뜻한 말투, 한국어로 대화
❷ 소크라테스식 스캐폴딩 대화 전략

직접적인 답변보다 질문을 통해 사용자의 사고를 자연스럽게 유도합니다.

단계유형예시 질문
1단계사실 확인"이 책에서 가장 기억에 남는 장면은 뭐였어?"
2단계해석"왜 그 장면이 기억에 남았다고 생각해?"
3단계연결"그 경험이 네 일상과 연결되는 부분이 있어?"
4단계평가"이 책을 읽고 나서 생각이 달라진 게 있어?"

대화 규칙: 한 번에 질문 최대 1개 / 답변 먼저 인정 후 다음 단계 / 단답 시 열린 질문 유도 / 충분한 생각 공유 시 정리

❸ 사용자 수준별 맞춤 응답
수준판별 기준톤답변 길이질문 레벨
beginner
초보 독서가		 totalBooks ≤ 5
totalNotes ≤ 10		 따뜻하고 격려 짧게 (3~5문장) 사실 확인 + 해석
steady
꾸준한 독서가		 totalBooks ≤ 20
totalNotes ≤ 50		 친근+분석적 중간 (5~8문장) 해석 + 연결
passionate
열정적 독서가		 totalBooks > 20
totalNotes > 50		 지적 파트너 깊이 있게 (8~12문장) 연결 + 평가
❹ 감정 인식 및 공감 응답
감정 패턴키워드대응 전략
좌절"어려워", "포기", "이해 안 돼"공감 → 정상화 → 작은 성취 상기
성취"다 읽었어", "목표 달성"함께 기뻐하기 → 구체적 칭찬 → 다음 단계 제안
호기심"궁금해", "왜 그럴까"질문 확장 → 탐구 유도 → 관련 책 연결
혼란"뭘 읽어야", "모르겠어"선택지 좁히기 → 취향 확인 → 맞춤 추천
공유 욕구"이 부분이 좋았어", "감동"적극적 경청 → 깊이 탐구 → 비슷한 감동 연결
❺ 안전 가드레일
  1. 도메인 한정: 독서/책/문학/기록/학습과 무관한 요청은 정중히 거절 + 독서 관련 대안 제시
  2. 숙제 대필 방지: 독후감/요약 직접 작성 요청 거절, 작성 가이드 제공
  3. 불확실성 인정: 모르는 책/정보는 솔직히 인정
  4. 개인정보: 실명/연락처 등 개인정보를 요청하지 않음
  5. 민감 주제: 정치/종교 등 논쟁적 주제는 책의 관점에서만
❻ Few-Shot 대화 예시

4가지 시나리오의 이상적 응답 패턴을 프롬프트에 포함하여 응답 일관성을 확보합니다.

시나리오사용자 발화 (예시)독서친구 응답 패턴
책 추천"요즘 뭐 읽을지 모르겠어"기분/취향 확인 질문으로 시작
책 토론"방금 데미안 다 읽었어"완독 축하 + 인상적 부분 질문
감정 공감"독서 목표 달성이 너무 어려워"공감 → 목표 조정 제안
도메인 외"수학 문제 풀어줘"정중 거절 + 독서 관련 대안

사용자 수준 자동 판별 로직

구현 위치: lib/ai/prompts/chat-prompts.ts — determineUserLevel(), generateUserLevelSection()

type UserLevel = "beginner" | "steady" | "passionate"; function determineUserLevel(context: ChatContext): UserLevel { const totalBooks = context.persona?.reading_stats?.totalBooks ?? 0; const totalNotes = context.persona?.reading_stats?.totalNotes ?? 0; if (totalBooks <= 5 && totalNotes <= 10) return "beginner"; if (totalBooks <= 20 && totalNotes <= 50) return "steady"; return "passionate"; }

동적 시스템 프롬프트 생성

구현 위치: lib/ai/prompts/chat-prompts.ts — generateDynamicSystemPrompt()

관리자 설정 템플릿을 기반으로, 다음 섹션들을 런타임에 동적으로 조합합니다:

  1. generatePersonaSection() — 사용자 페르소나 (독서 속도, 기록 스타일, 활동 시간, 선호 장르)
  2. generateUserLevelSection() — 사용자 수준별 톤/길이/질문 조정
  3. generateRecentBooksSection() — 최근 읽은 책 ([[book:ID:제목]] 링크 형식)
  4. generateRecentNotesSection() — 최근 기록 ([[note:ID:타입]] 링크 형식)
  5. generateReadingGoalSection() — 올해 독서 목표/진행률
  6. generateMemorySection() — 장기 기억 주입
  7. generateModeInstruction() — 대화 모드별 지시문

3. Phase 2: 대화 모드 + 퀵 액션

P0 핵심

5가지 대화 모드

타입 정의: types/ai/chat.ts — ChatMode, CHAT_MODE_INFO

💬 자유 대화

general — 아이콘: MessageCircle

독서에 대해 자유롭게 이야기합니다. 기본 모드로, 별도의 모드 지시문 없이 6섹션 기본 프롬프트만 적용됩니다.

🗪 책 토론

discuss — 아이콘: MessagesSquare

소크라테스식 질문을 적극 활용하여 다양한 관점과 해석을 제시합니다. 저자의 의도, 시대적 배경, 다른 독자의 해석 등을 소개하며 지적 토론 분위기를 유지합니다.

🔖 책 추천

recommend — 아이콘: BookMarked

3단계 추천: 맞춤 추천(취향 기반) / 도전 추천(새로운 장르) / 의외의 추천. [[recommend:「제목」:저자명]] 형식으로 자동 서재 등록을 지원합니다.

🎯 독서 코칭

coaching — 아이콘: Target

자기결정이론(SDT) 기반으로 자율성/유능감/관계성을 지원합니다. SMART 목표 설정, 진행률 참조, 작은 성취 인정, 선택지 제시 전략을 사용합니다.

🧠 독서 퀴즈

quiz — 아이콘: BrainCircuit

4가지 유형(내용 확인/해석/적용/비평) 문제를 1개씩 출제합니다. 틀리면 정답 대신 힌트를 제공하여 다시 생각하게 유도합니다.

💡
모드 지시문 구현: lib/ai/prompts/chat-prompts.ts — generateModeInstruction(mode) 함수가 general 외 모드에 대해 추가 프롬프트 지시문을 반환합니다. 이 지시문은 generateDynamicSystemPrompt()에서 시스템 프롬프트 끝에 추가됩니다.

4. Phase 3: 장기 기억 파이프라인

P1

메모리 추출 파이프라인

💬 AI 응답 완료 → 🚀 fire-and-forget 비동기 추출 → 🤖 gemini-2.0-flash 분석
📋 JSON 구조 추출 → ✅ confidence ≥ 0.7 필터 → 💾 DB 저장 (LRU 50개)
🔄 다음 대화 시 시스템 프롬프트에 주입

파이프라인 상세 동작

1

AI 응답 완료 후 비동기 트리거

app/api/ai/chat/route.ts — extractAndSaveMemories() 를 .catch()로 감싸서 fire-and-forget 호출. enableLongTermMemory 플래그가 true일 때만 실행. 사용자 응답 지연 없음.

2

Gemini 2.0 Flash로 대화 분석

비용 효율적인 gemini-2.0-flash 모델로 사용자 메시지 + AI 응답 쌍을 분석합니다. lib/ai/prompts/memory-prompts.ts — MEMORY_EXTRACTION_PROMPT 템플릿에 기존 기억과 대화 내용을 주입합니다.

3

JSON 구조 추출 및 파싱

응답에서 [{memory_type, content, confidence}] JSON 배열을 정규식으로 추출합니다. 파싱 실패 시 조용히 무시하여 안정성을 확보합니다.

4

Confidence 필터링 (0.7 이상)

추측이 아닌 명확히 드러난 정보만 저장합니다. confidence < 0.7인 항목은 건너뜁니다.

5

LRU 관리 (최대 50개)

동일 memory_type + content 중복 체크 후 저장. 최대 50개 초과 시 가장 오래된 메모리 삭제 (updated_at 기준 LRU).

6

다음 대화 시 시스템 프롬프트에 주입

app/actions/ai/chat.ts — getChatContext() 에서 user_ai_memories 테이블 조회 → lib/ai/prompts/chat-prompts.ts — generateMemorySection()에서 유형별 그룹핑 후 프롬프트에 삽입. "지난번에 말씀하셨듯이" 등 자연스러운 활용을 유도합니다.

메모리 5가지 유형

정의 위치: lib/ai/prompts/memory-prompts.ts — MEMORY_EXTRACTION_PROMPT, MEMORY_TYPE_LABELS

유형라벨설명예시
reading_preference독서 취향선호 장르, 작가, 스타일"SF와 판타지 장르를 좋아함"
interest관심 분야독서 외 취미, 직업, 관심사"인공지능, 역사에 관심"
