- **전수 진단(102곡 — ffprobe·silencedetect·스펙트럼·loudnorm·chromaprint 지문 교차대조):**
  - **재즈 중복:** `dreamy-jazz.mp3` == `groovy-jazz.mp3` 바이트 동일. Mixkit 645(Dreamy Jazz)·646(Groovy Jazz)이 **같은 음원·같은 파형**을 서빙한다. 같은 곡이 두 이름으로 셔플에 들어가 "겹쳐" 들렸다. 109 BPM 이라 Groovy Jazz 로 남기고 Dreamy Jazz 제거(34곡).
  - **피아노 이어붙음:** `bach-wtc-prelude-c.mp3` = 프렐류드(0–123s)+**푸가**(128–310s), `debussy-arabesque-1.mp3` = 1번(0–255s)+**2번**(262–465s). 한 파일에 두 곡이라 "곡이 중간에 바뀜".
  - **클리핑:** v4 빌드의 `alimiter=limit=-1.5dB` 는 **dB 접미사가 파싱되지 않아 무효** — 약 50곡이 0 dBTP 초과(최대 +0.6). build-ambience.ts 에서 이미 알려진 함정이 음악 빌드에도 그대로 있었다.
  - **음질 하락:** 2026-03 원본(Musopen FLAC→320k 등)을 v4 가 VBR V2(~190k)로 재인코딩. 다수 곡 16 kHz 컷오프.
  - **출처 소실:** `tracks.ts` 의 `sourceUrl` 이 산출물 경로(`/music/…`)를 가리켜 재다운로드가 불가능한 구조였고, 재즈 원본을 두던 음악용 Supabase 프로젝트는 **DNS 해석 불가(소실)**. 원본 320k 파일은 git 최초 커밋(b9af403·6ea6ddb·e8c66aa·13f4eab)에만 남아 있었다.
