## 1. 메뉴별 현재 기능 현황

### 1-1. 홈 대시보드 (`/`)

| 구성 요소 | 현재 상태 | 비고 |
|-----------|----------|------|
| Primary Zone (인사말+핵심지표+주간진행바) | ✅ 완성 | Streaming SSR |
| Secondary Zone (계속읽기+최근진행) | ✅ 완성 | 2열 그리드 |
| Tertiary Zone (캘린더+최근기록) | ✅ 완성 | 데스크톱 우측/모바일 접이식 |
| 퀵 액션 버튼 | ✅ 완성 | 책 추가, 기록 작성, AI 채팅 |
| 게스트 배너 | ✅ 완성 | 가입 유도 CTA |

**개선 제안:**
- **[H-1] 계속 읽기 카드에 마지막 기록 시간 표시** — "3일 전에 읽었어요" 같은 넛지로 복귀 유도
- **[H-2] 주간 목표 미달성 시 격려 메시지** — 현재 진행바만 있고 감정적 피드백 부재
- **[H-3] "오늘의 추천" 영역 추가** — AI 기반으로 읽던 책의 다음 행동 제안 (기록 작성, 완독 등)

| 일괄 등록 (`/books/bulk`) | ✅ 완성 | |
| 서재 관리 (`/bookshelves`) | ✅ 완성 | AI 자동 정렬 포함 |

**개선 제안:**

- **[B-2] 책 정렬 옵션 확대** — 현재 상태 필터만 있고, "최근 읽은 순", "진행률 순", "추가일 순" 정렬 미지원
- **[B-3] 완독 책 재독 전환 UX** — 완독 상태에서 "다시 읽기" 버튼이 상세 페이지에만 있음. 서재 목록에서 바로 전환 가능하면 편리

### 1-3. 책 상세 (`/books/[id]`)

| 구성 요소 | 현재 상태 | 비고 |
|-----------|----------|------|

| 진행률 슬라이더 | ✅ 완성 | 인라인 메모 지원 |

| 페이지 수 편집 | ✅ 완성 | ISBN 자동 조회 |
| AI 리포트 버튼 | ✅ 완성 | 최소 3개 노트 필요 |
| 연결된 책 관리 | ✅ 완성 | |
| 책 삭제 | ✅ 완성 | |

**개선 제안:**
- **[BD-1] 기록 0건일 때 빈 상태 가이드** — "아직 기록이 없어요. 읽으면서 인상깊은 구절을 남겨보세요" + CTA 버튼. 현재 빈 상태 표시가 generic함
- **[BD-2] 진행률 변경 히스토리 시각화** — 독서 여정 탭에 진행률 그래프 추가 (날짜별 페이지 변화 선 그래프)
- **[BD-3] 읽는 이유 입력 유도** — 현재 "읽는 이유" 필드가 숨겨져 있어 대부분 미입력. 책 추가 직후 또는 상세 첫 방문 시 가볍게 물어보는 UX

### 1-5. 기록 작성/편집 (`/notes/new`, `/notes/[id]/edit`)

| 구성 요소 | 현재 상태 | 비고 |
|-----------|----------|------|
| 구절/생각 분리 입력 | ✅ 완성 | BookMentionTextarea |
| 이미지 업로드 (사진/필사) | ✅ 완성 | OCR 지원 |
| 태그 입력 | ✅ 완성 | 자동완성 |
| 출처 입력 (자유 기록) | ✅ 완성 | 4가지 타입 |
| 공개 설정 | ✅ 완성 | |
| Draft → Published 전환 | ✅ 완성 | |

**개선 제안:**
- **[NF-1] 기록 작성 진입 간소화** — 현재 "책 선택 → 폼" 2단계. 모바일 FAB 클릭 시 최근 읽던 책이 자동 선택되어 바로 입력 가능하면 마찰 감소
- **[NF-2] 음성 입력 지원** — Web Speech API로 음성→텍스트 변환. 이동 중이나 손이 불편할 때 유용
- **[NF-3] 기록 템플릿** — "오늘의 한 줄", "인상적인 구절 + 내 생각", "독후감" 같은 템플릿 선택으로 진입 장벽 낮추기

## 2. 크로스 기능(Cross-Feature) 개선 제안

### 연결 흐름 끊김 문제

| 코드 | 문제 | 개선 |
|------|------|------|
| **[X-1]** | 책 상세 → 기록 작성 후 책 상세로 돌아오지 않음 | 기록 저장 후 `returnTo` 파라미터로 원래 페이지 복귀 |
| **[X-2]** | 모임 서재 책 → 개인 기록이 연결 안 됨 | 모임 책 상세에서 "내 기록 보기" 링크 추가 |
| **[X-3]** | 포인트 적립 시 토스트만 표시 | 어떤 행동으로 몇 P 적립됐는지 상세 피드백 ("+15P 기록 작성") |
| **[X-4]** | 검색 → `/notes?q=` 리다이렉트만 | 통합 검색에서 책/기록/모임 동시 검색 결과 표시 |

### 알림 시스템 부재

| 코드 | 현재 상태 | 필요성 |
|------|----------|--------|
| **[X-5]** | 인앱 알림 없음 | 모임 활동, 스트릭 위험, 완독 축하, AI 리포트 완성 등에 알림 필요 |
| **[X-6]** | 이메일 알림 없음 | 3일 이상 미접속 시 "다시 읽어볼까요?" 리마인더 |

### 온보딩 흐름

| 코드 | 현재 상태 | 개선 |
|------|----------|------|
| **[X-7]** | 온보딩 후 홈으로 바로 이동 | 첫 책 추가 → 첫 기록 작성까지 가이드 투어. 현재 튜토리얼 페이지는 있으나 실제 행동으로 연결 부족 |

## 3. 우선순위 매트릭스

### P0 — 즉시 적용 (사용성 직결)

| 코드 | 제안 | 영향도 | 난이도 |
|------|------|--------|--------|
| [P-1] | 포인트 소비처 비용 확정 및 안내 | 높음 | 낮음 |
| [X-1] | 기록 저장 후 원래 페이지 복귀 | 높음 | 낮음 |
| [X-3] | 포인트 적립 상세 피드백 | 중간 | 낮음 |
| [BD-1] | 책 상세 기록 빈 상태 가이드 | 중간 | 낮음 |

### P1 — 단기 개선 (1~2주)

| 코드 | 제안 | 영향도 | 난이도 |
|------|------|--------|--------|
| [H-1] | 계속 읽기 카드에 마지막 기록 시간 | 중간 | 낮음 |
| [B-2] | 서재 정렬 옵션 확대 | 중간 | 중간 |
