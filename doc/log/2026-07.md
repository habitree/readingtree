### 2026-07-07 — 배경음악 v2: 음질·다양성·셔플 재생 전면 개편 (4채널 103곡)
- **카테고리:** #음악 #음질 #다양성 #셔플 #Supabase #스토리지
- **중요도:** P1
- **지시:** "현재 설정되어있는 음악들을 음질개선과 다양성 개선 그리고 사용자들이 들을때마다 다른음악이 들리도록 업데이트 기획해서 적용. Supabase 연동하여 실제 데이터 작업까지 직접진행."
- **음질:** 인코딩 128k→**160kbps CBR**(원본 대부분 160~320k, 무료 티어 스토리지 1GB·에그레스 5GB 고려해 192k 대신 160k 채택). **EBU R128 측정 기반 선형 게인 정규화**(목표 -16 LUFS, 트루피크 -1.5dBTP 캡, volume 필터만 적용 → 다이내믹 무압축) — 조용한 클래식(-26 LUFS대)과 시끄러운 재즈(-10 LUFS대)의 곡 간 볼륨 편차 해소. 앞뒤 무음 트리밍(-50dB, 앞 0.5s/뒤 0.8s 여유).
- **다양성:** 2채널(클래식 49/재즈 35) → **4채널 103곡**. 🎹 피아노 30곡(138분) / 🎻 클래식 현악·관현악 24곡(152분) / 🎺 활기찬 클래식 14곡(79분) / 🎷 재즈 35곡(67분). 미사용 로컬 음원 중 128kbps 이상 19곡 추가(알비노니 아다지오, 예수 인간 소망의 기쁨, 토카타와 푸가, 쇼팽 녹턴 Op.48-1, 포레 파반, 보칼리제 등). `tracks.ts`에 `channel` 필드 신설(era 대신 채널이 분류 단일 기준).
- **셔플(들을 때마다 다른 순서):** 기존 "고정 순서+랜덤 위치 시작"(다음 곡은 항상 동일) → **곡 단위 Fisher-Yates 셔플 큐**. 채널 선택 시 큐 생성, 곡 경계에서 다음 셔플 곡의 (파트, 오프셋)을 비활성 audio에 프리로드 후 스왑(250ms 페이드인, 무중단). 큐 소진 임박 시 직전 곡 연속 중복을 피해 자동 연장. 부수 효과로 **다음 곡 스킵 버튼** + Media Session `nexttrack` 추가 가능해짐. 폴백 전환 시 이중 스킵 방지 `isTransitioning` 가드.
