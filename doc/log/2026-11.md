### 2026-11-09 — 독서 기록 일시정지/재개 (음악 플레이어식 토글) · REQ-0013
- **카테고리:** #기록 #타이머 #UX #DB
- **중요도:** P1
- **지시:** "기록시작 이후 일시정지 기능을 심플하게 — 음악처럼 멈추고 다시 시작. 메인 가운데 버튼 클릭 시 보이는 저장 화면에서 일시정지/시작 버튼으로 직관적으로."
- **발견:** 기존 '멈춤'(사이드바·홈 카드)은 이름과 달리 **종료 시트를 여는 버튼**이었고, 일시정지 상태는 어디에도 없었다(경과 = now − started_at).
- **결정(사용자 선택):** 일시정지 상태는 DB 저장(기기·탭 동기화), 사이드바·홈 카드 '멈춤'은 일시정지/재개 토글로 전환. 종료는 가운데 버튼/헤더 pill → 저장 시트.
- **구현:**
  - DB: `reading_logs.paused_at`, `paused_seconds`(기본 0, CHECK ≥0) — 추가형·멱등, 적용 완료.
  - 활성 시간 단일 출처 `lib/utils/session-time.ts` `computeActiveSeconds` = (paused_at ?? now) − started_at − paused_seconds. 서버 저장(end/cancel)과 클라 표시가 같은 식 사용.
  - 서버: `setSessionPaused(sessionId, paused)` 멱등 액션. 종료 시 진행 중 일시정지 구간을 누적에 합쳐 닫음.
  - 클라: zustand 낙관 override(탭 즉시 반영) → 서버 확정 → `session-updated` 브로드캐스트. override는 확정 이후 시작된 응답이 오면 제거(오래된 폴링 응답 깜빡임 방지). 일시정지 중엔 1초 tick 중단. 목표시간 다이얼로그는 elapsed 기반이라 자동으로 쉰 시간 제외.
  - UI: 저장 시트 상단 경과시간 옆 큰 ⏸/▶ 원형 버튼, 일시정지 시 회색+깜빡임. 하단 가운데 FAB·헤더 pill에 ⏸ 배지/회색. 그리드 카드는 폴링 없는 store 전용 훅(`useSessionPauseControl`).
