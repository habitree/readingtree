  - `next.config.js` remotePatterns 와 `image-proxy` 허용목록에 `contents.kyobobook.co.kr` 추가.
- **검증:** vitest 7건 통과(서지 요청 파라미터 1건·교보 표지 폴백 1건 신규), tsc 0 에러, eslint 0. 교보 표지 경로는 실측(실 ISBN 3건 200 / 허위 ISBN 4건 404)으로 확인.
- **실측 검증(같은 날, 로컬 PC):** 서지 API 를 실제 호출 — 종전 파라미터는 `"트렌드 코리아"` 10건 중 2027 없음, 신규 파라미터는 18건 중 2027 이 1순위. 로컬 dev 서버 `/api/books/search` 에서 `트렌드 코리아`·`트렌드코리아`·`김난도` 모두 신간이 맨 위 + 교보 표지 부착 확인. 교보 `/pdt/` 는 없는 ISBN 에 404 가 아니라 **403** 을 준다(`res.ok` 판정이라 동작 동일).
- **실측에서 나온 부작용 수정:** 출간일 역순이라 ISBN 만 선등록된 **출간 예정작**이 맨 위로 왔다(`"해리 포터"` → 2026-12-31 예정 2건). 출간일이 오늘(KST) 이후인 서지는 신간 보충에서 제외. 회귀 테스트 1건 추가(vitest 8건).

### 2026-11-18 — 책 검색 소스 재교체 (알라딘 OpenAPI 종료 대응)
- **카테고리:** #도서검색 #외부API #장애
- **중요도:** P0
- **지시:** "도서검색의 데이터가 잘 나오지 않고 이미지가 잘 보이지 않는 이유 확인해서 디테일 점검 후 업데이트."
- **원인:** 알라딘 OpenAPI가 **2026-11-01 종료** — `ItemSearch` 가 `errorCode 999 "www.aladin.co.kr 도메인을 통한 OpenAPI서비스는 종료"` 를 200으로 반환(item 배열 없음) → 코드상 "0건"으로 처리돼 **모든 검색이 Google Books 폴백으로만** 흘렀다. Google Books는 한국 도서에 약해 무관한 책 혼입(예: "역행자"→판타지 소설), 표지 결손("불편한 편의점" 6건 중 5건), 출판사 누락, 부분 출간일. 부수로 image-proxy 허용목록에 `books.google.com` 이 없어 Google 표지는 공유/캡처 경로에서 403.
- **결정(사용자 선택):** 국립중앙도서관 소장자료 검색을 주력으로 즉시 교체 + 카카오 책 검색은 `KAKAO_REST_API_KEY` 설정 시 1순위로 자동 활성.
- **구현:** `lib/api/book-search.ts` — 카카오(키 있을 때) → 국중도(`NL/search/openApi/search.do`, 기존 `NL_SEOJI_CERT_KEY`) → Google Books. 국중도: 검색 하이라이트 HTML 제거, 소장 레코드 중복 ISBN 제거, 저자 역할어/생몰년/역자 정리, "파주 : 창비, 2007" 형식 출판사 정리, 표지 `https://cover.nl.go.kr/` 접두, 표지 없는 건은 Google ISBN 조회로 보충(ISBN당 1일 캐시). Google 표지 `edge=curl` 제거. 알라딘 검색 코드 제거.
- **추가(같은 날, 사용자 재확인 "트렌드 코리아 2027 안 나옴"):** 국중도 소장자료는 납본·정리 후에야 잡혀 신간이 수개월 늦다(2026-09-30 출간작이 11-18에도 0건). 첫 페이지에 서지(ISBN 등록) API를 병행 — 종이책 + 제목이 검색어로 시작하는 것만, 소장자료에 없는 것 최대 3건을 앞에 배치. 신간 표지는 국중도·Google 모두 없어 카카오 키 전까지 빈 표지. 또한 변경이 **미배포(미커밋)** 상태였음.
- **실측(라이브):** 표지 보유율 채식주의자 7/9 · 불편한 편의점 6/10 · 역행자 7/10 · 트렌드 코리아 2026 2/4, 결과 관련성 정상, 응답 1~1.7초.
- **검증:** vitest 신규 5건 통과, tsc 0 에러, eslint 0.
- **한계/후속:** 국중도는 출간일이 대부분 연도만 와서 `published_date` 가 null(지어내지 않음 원칙) — 카카오 키 등록 시 해소. Google Books 일일 쿼터는 표지 보충으로 사용량 증가. `lib/api/book-page-count.ts` 의 알라딘 ItemLookUp, `app/actions/admin/stats.ts` 의 알라딘 상태 표시는 죽은 경로로 남아 있음(범위 밖, 보고만).
- **변경 파일:** `lib/api/book-search.ts`, `app/api/image-proxy/route.ts`, `app/api/books/search/route.ts`(주석), `__tests__/lib/book-search.test.ts`
