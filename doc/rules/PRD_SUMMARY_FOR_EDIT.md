## 1. 개요 (Executive Summary)

### 1.1 제품 비전
ReadTree는 독서를 좋아하는 사람들이 인상 깊었던 문장을 다시 찾고, 흩어진 기록을 한 곳에서 관리하며, 쉽게 공유할 수 있게 해주는 책 전용 기록·공유 플랫폼입니다.

### 1.2 핵심 가치 제안
**"기록을 다시 찾고, 정리하고, 공유할 수 있는 경험 제공"**

- **기록 통합**: 사진, 필사, 메모, 인상 깊은 문장이 하나의 책 단위로 자동 연결
- **즉시 검색**: 문장 단위 검색으로 언제든 원하는 기록을 찾을 수 있음
- **쉬운 공유**: 한 번의 클릭으로 SNS 카드뉴스 형태로 공유 가능

### 1.3 목표 고객
- **메인 페르소나**: 꾸준히 책을 읽고 기록하려는 개인 독자
- **서브 페르소나 1**: 독서모임 운영자
- **서브 페르소나 2**: 북튜버·지식 콘텐츠 크리에이터

---

## 2. 문제 정의 (Problem Statement)

### 2.1 핵심 문제
"책에 대한 나의 기록을 언제든 다시 찾을 수 있는 저장소"가 필요하나, 현재 솔루션(특히 노션)은 책 기록에 최적화되지 않았고, 템플릿을 직접 만들거나 구매해야 해 일반 독자가 꾸준히 쓰기 어렵다.

### 2.2 문제의 결과
1. 기억하고 싶은 문장을 다시 찾기 어렵다  
2. 독서 히스토리가 축적되지 않는다  
3. 모임·SNS에서 공유하려는 욕구가 좌절된다  
4. 나의 독서 타임라인이 사라진다  

### 2.3 감정적 영향
감정적 상실("내가 읽은 것들이 사라지는 느낌") → 독서 습관·성장 흐름 단절

---

## 3. 제품 목표 (Product Goals)

### 3.1 비즈니스 목표
- 초기 3개월 내 WAU 1,000명
- 기록 재사용률 30% 이상
- 사용자당 월평균 공유 5회 이상
- 재방문율 40% 이상
- 독서모임 참여율 20% 이상

### 3.2 사용자 목표
- 독서 기록 안전 보관·언제든 찾기
- 독서 습관 지속 동기 부여
- 독서 커뮤니티 형성·활성화

---

## 4. 기능 요구사항 (Functional Requirements)

### 4.1 핵심 기능 (MVP)
- **4.1.1** 사용자 인증 및 온보딩 (소셜 로그인, 목표 설정, 튜토리얼)
- **4.1.2** 책 관리 (네이버 검색 API, 책 정보·표지)
- **4.1.3** 기록 기능 (필사, 사진, 메모, OCR, 자동 정리)
- **4.1.4** 검색 기능 (문장 단위, 책/날짜/태그/필사 유형/전체 텍스트)
- **4.1.5** 공유 기능 (카드뉴스, 인스타/카카오/블로그)
- **4.1.6** 타임라인 기능 (독서 타임라인, 독서 통계)
- **4.1.7** 독서모임 기능 (모임 생성·참여, 대시보드)

### 4.2 향후 기능 (Post-MVP)
- 고급 검색 (AI 문장 추천, 유사 문장 검색)
- 독서 리포트 (주간/월간 자동 생성)
- 크리에이터 기능 (챌린지, 커뮤니티)
- Book Circulation (대여, 중고, 선물)

---

## 5. 비기능 요구사항 (Non-Functional Requirements)

- **성능**: 페이지 로딩 3초 이내, 검색 1초 이내, 이미지 최대 5MB·다중 업로드
- **보안·프라이버시**: 기본 비공개, 사용자 선택 공개, 암호화, RLS
- **확장성**: 초기 1,000명, Supabase 기반
- **호환성**: Chrome/Safari/Firefox 최신, 반응형 모바일 웹

---

## 6. 기술 스택 (Technology Stack)

- **프론트/백**: Next.js (SSR, API Routes, 이미지 최적화)
- **DB·스토리지**: Supabase (PostgreSQL, RLS, Realtime, Full-text Search, Storage)
- **인증**: Supabase Auth (카카오·구글 소셜, 세션·프로필)
- **AI**: Gemini API (표지 인식, OCR, 텍스트 추출·분석)

---

## 7. 데이터 모델 (Data Model) — 요약

- **Users** (auth.users 연동, reading_goal 등)
- **Books** (isbn, title, author, publisher, cover_image_url 등)
- **UserBooks** (user_id, book_id, status, started_at, completed_at)
- **Notes** (user_id, book_id, type: quote/memo/photo/transcription, content, is_public)
- **Groups** (name, leader_id, is_public)
- **GroupMembers** (group_id, user_id, role)
- **GroupBooks** (group_id, book_id, target_completed_at)

---

## 8. 사용자 경험 (User Experience)

- **고객 여정**: Day 1 가입·첫 기록 → Day 2 자동 정리 → Day 3 공유 → Day 5 모임 → Day 7 타임라인·통계
- **WOW 모멘트**: 첫 자동 정리, 문장 검색 성공, 공유 후 반응, 타임라인 조회

---

## 9. 성공 지표 (Success Metrics)

- **North Star**: WAU/MAU (목표: 3개월 내 WAU 1,000)
- **기능별**: 기록 재사용률 30%+, 공유 5회/월+, 재방문 40%+, 독서모임 20%+
- **만족도**: NPS 50+, 3개월 유지율 30%+

---

## 10. 리스크 및 대응 (Risks & Mitigation)

- **기술**: OCR 정확도 → Gemini·수동 보정 / 이미지 성능 → 최적화·비동기·CDN
- **제품**: 재방문 부족 → 리포트·알림·모임 / 공유 매력 부족 → 템플릿·피드백·SNS
- **비즈니스**: 경쟁 → 차별화·커뮤니티·빠른 개선

---

## 11. 개발 로드맵 (Development Roadmap)

- **Phase 1 (3개월)**: MVP — 인증, 책, 기록, 검색, 공유, 타임라인, 독서모임 기본
- **Phase 2 (3개월)**: 고급 검색, 독서 리포트, 공유 템플릿, 모임 대시보드 고도화
- **Phase 3 (6개월)**: 크리에이터, AI 추천, Book Circulation(검토)
