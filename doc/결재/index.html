1. 한 줄 요약

현재 비용은 Cloud Run에 호스팅된 OCR 함수 extractTextFromImage가 내부에서 호출하는 Google Vision API에서 대부분 발생한다. Cloud Run 자체는 무료 티어 안에 있을 가능성이 높고, 진짜 과금 항목은 Vision API 호출 건수다.

Gemini API 키와 멀티모달 모델이 이미 코드베이스에 있으므로, OCR을 Gemini Vision으로 통합하면 월 비용을 ₩0에 근접시킬 수 있다.

2. 🔴 보안·코드 점검 결과 — 비정상 호출 4건 발견

"사용자도 적은데 OCR이 너무 많이 발생한다"는 직감이 정확했습니다. /admin/api-info 페이지가 진입 시마다 자동으로 진짜 Vision API를 호출하고 있고, 이 호출은 ocr_logs 통계에 잡히지 않아 발견되지 않은 사일런트 과금이었습니다.

순위경로통계 기록비용 영향
1 testOcrConnection() — admin 페이지 자동 호출 (1x1 PNG 진짜 전송) ❌ 안 잡힘 매우 큼
2 batchProcessOCR() — Rate Limit·한도·소유권 모두 우회 + failed 노트 반복 처리 ✅ 잡힘 큼
3 OCR 결과 캐시 부재 → 동일 이미지 재호출 시 매번 Vision API 호출 ✅ 잡힘 중간
4 Cloud Run 함수 unauthenticated 의심 → 외부 abuse 가능 (코드에 "공개 함수 가정" 분기 존재) ❌ 안 잡힘 잠재적 큼

왜 사일런트인가

  • 그러나 GCP 결제는 함수·API 호출 단위로 정확히 집계됨
  • admin 페이지 새로고침 100번 = Vision API 100회 호출. 4월 비용의 큰 부분일 가능성

3순위 — 결과 캐시 부재

lib/api/cloud-run-ocr.ts에 캐시 레이어가 없음. 같은 이미지를 여러 번 호출하면 매번 Vision API 호출. 이미지 콘텐츠 SHA-256 hash 기반 ocr_cache 테이블로 중복 제거.

4순위 — Cloud Run 인증 (보안 + 비용)

cloud-run-ocr.ts:101의 "인증 정보가 없습니다. 공개 함수로 가정합니다." 분기는, Cloud Run 함수가 allUsers로 노출됐을 가능성을 시사합니다. 누구든 함수 URL(extracttextfromimage-236647437750.us-central1.run.app, 코드에 하드코딩됨)을 알면 인증 없이 호출 가능 → 비용은 우리 결제 계정으로.

# IAM 점검
gcloud run services get-iam-policy extracttextfromimage \
  --project=habitree-f49e1 --region=us-central1

# allUsers 보이면 즉시 제거
gcloud run services remove-iam-policy-binding extracttextfromimage \
  --project=habitree-f49e1 --region=us-central1 \
  --member="allUsers" --role="roles/run.invoker"
예상 효과 ─ 1순위 패치 한 줄만 적용해도 다음 결제일 비용이 거의 0에 수렴할 가능성이 매우 높음. 상세 분석·추가 위험·전체 체크리스트는 보안점검.md 참조.

왜 옵션 B(Gemini Vision)가 1순위인가
  1. Gemini API 키와 @google/generative-ai 클라이언트가 이미 코드에 있음
  2. Gemini 2.0 Flash 멀티모달이 한글 OCR 실용 수준 정확도를 제공
  3. AI Studio 무료 티어가 큼 (월 ~45,000 RPD)
  4. Cloud Run + Vision API 둘 다 폐기 가능 → 비용 0원에 근접
  5. OCR과 "이게 책 제목인지 분류" 단계를 한 호출로 합칠 수 있어 호출 수 자체가 감소

Gemini Vision PoC 코드 스케치

// lib/api/gemini-ocr.ts (신규)
import { GoogleGenerativeAI } from "@google/generative-ai";

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);

export async function extractTextFromImageGemini(imageUrl: string) {
  const res = await fetch(imageUrl);
  const buf = await res.arrayBuffer();
  const base64 = Buffer.from(buf).toString("base64");
  const mimeType = res.headers.get("content-type") || "image/jpeg";

  const model = genAI.getGenerativeModel({ model: "gemini-2.0-flash" });
  const result = await model.generateContent([
    { inlineData: { data: base64, mimeType } },
    { text: "이 이미지의 모든 텍스트를 줄바꿈을 유지해 그대로 추출. 설명 없이 텍스트만." },
  ]);
  return result.response.text().trim();
}

6. 권장 실행 순서

즉시 (이번 주)

  1. 예산 알림 설정 — 월 ₩10,000 한도, 50/90/100% 이메일 (3분)
  2. Cloud Run IAM 점검 — 서비스 계정만 호출 가능하도록 roles/run.invoker 제한 (5분)
  3. OCR 결과 캐싱 — Supabase ocr_cache (image_hash text PK, text) 테이블 (반나절)
  4. 사용자별 일 호출 제한 — 기존 rate_limits RPC에 OCR 항목 추가 (반나절)

단기 (2주 내)

  1. Gemini Vision PoC 작성 (반나절)
  2. 트래픽 10%만 Gemini로 보내며 정확도 비교 (1주)
  3. OK이면 100% 전환 → Cloud Run·Vision 사용 중단 (1일)

중장기

  1. 한글 정확도 이슈가 생기면 Naver Clova OCR 추가 검토
  2. 사용자 1만 명+ 도달 시 비용 모델 재검토
