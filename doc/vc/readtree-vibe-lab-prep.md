# ReadTree: Vibe Labs Seoul 2026 지원 준비 및 개선 계획

Vibe Labs Seoul 2026 프로그램의 핵심 철학(**속도, 결과물, ARR**)에 맞춰 ReadTree 프로젝트의 현재 상태를 진단하고, 선발 가능성을 높이기 위한 개선 사항을 정리합니다.

## 1. 현재 상태 진단 (As-Is)
- **제품**: MVP 수준의 기능을 갖춘 책 전용 기록 플랫폼 (Next.js + Supabase 기반)
- **핵심 기능**: 도서 검색, AI OCR 기반 필사 기록, 감각적인 카드 공유
- **수익 모델**: 현재 무료 (수익 모델 미정)
- **속도**: 1인 빌더 수준의 개발 속도

## 2. Vibe Labs 최적화 개선 사항 (To-Be)

### 📈 [수익] "Free MVP"에서 "First $1"로 전환
Vibe Labs는 ARR(연간 반복 매출)을 가장 중요한 지표로 봅니다.
- **개선**: 현재의 "전면 무료" 정책에서 일부 고급 기능을 활용한 **수익성 검증(Validation)** 단계로 진입합니다.
    - **Pro 플랜 프리뷰 도입**: "고급 독서 리포트", "무제한 OCR", "프리미엄 공유 템플릿" 등을 포함한 가상의 유료 플랜 버튼을 배치하여 클릭률(Conversion intent) 측정.
    - **커피 한 잔 후원하기**: 실제 사용자 경험을 해치지 않는 선에서 초기 결제 의사를 확인하는 장치 마련.

### ⚡ [속도] 바이브 코딩(AI-Native Development) 증명
설명이 아닌 누적된 실행의 결과물(커밋 로그, 반복 주기)을 보여줘야 합니다.
- **개선**: AI Agent(Antigravity 등)와의 협업 과정을 체계화하고 가시화합니다.
    - **Changelog 자동화**: 매일의 주요 변경 사항과 사용자 피드백 반영 사항을 라이브 페이지에 노출.
    - **커밋 로그 밀도 강화**: 기능 단위의 잦은 업데이트와 반복(Iteration) 기록을 Git 저장소에 축적.

### 📊 [지표] 대시보드 기반의 의사결정 (Proof over Pitch)
피치덱이 아닌 숫자로 이야기할 준비가 필요합니다.
- **개선**: 프로젝트 내부에 핵심 지표(North Star Metric) 측정 시스템을 구축합니다.
    - **핵심 지표 설정**: 주간 활성 사용자(WAU), 기록 생성 수, 카드 공유 횟수, OCR 성공률.
    - **관리자 데모 모드**: 선발 과정에서 보여줄 수 있는 실제 데이터 대시보드(Internal Dashboard) 구현.

### 🚀 [성장] GTM(Go-To-Market) 실험 및 채널 발견
"모든 채널이 아닌, 작동하는 1개 채널"을 찾아야 합니다.
- **개선**: 독서 커뮤니티 타겟 마케팅 실험을 시작합니다.
    - **타겟 확보**: 북스타그램(인스타그램), 트레바리 등 기존 독서모임 채널을 대상으로 한 '카드 공유 기능' 바이럴 유도.
    - **바이럴 루프**: 카드 뉴스 하단에 `ReadTree` 워터마크 및 QR 코드를 포함하여 신규 사용자 유입 경로 추적.

## 3. 프로그램 지원 전 액션 아이템 (Checklist)

- [ ] **수익 검증**: 최소 1개 이상의 유료 전환 유도 버튼 또는 후원 모델 배치
- [ ] **데이터 대시보드**: Supabase 쿼리를 활용한 주요 지표 시각화 (v0 또는 Recharts 활용)
- [ ] **AI 협업 로그**: AI를 활용한 비약적인 개발 속도 향상 사례 문서화
- [ ] **실제 사용자 확보**: 지원 마감(2/19) 전까지 최소 100명의 활성 사용자 및 500개 이상의 실제 기록 데이터 확보
- [ ] **라이브 URL 최적화**: Vercel 배포 상태 및 모바일/PWA 사용성 최종 점검
