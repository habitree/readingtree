## 2. 피치 스토리 구성

### 내러티브 아크

```
문제 공감 → 해결책 제시 → 제품 증명 → 실행력 증명 → 비즈니스 가능성 → 행동 유도
```

### 핵심 메시지 3가지

1. **"모든 독서인의 보편적 고통을 AI로 해결한다"**
   - 2,000만 독서 인구의 기록 단절 문제
   - AI OCR + AI 채팅 + 게이미피케이션 삼위일체

2. **"Vibe Coding의 살아있는 증거다"**
   - 1인이 2개월 만에 25 테이블, 150+ 컴포넌트 구축
   - Claude Code와의 협업으로 엔터프라이즈급 아키텍처

3. **"ARR을 만들 준비가 되어있다"**
   - Freemium 모델 설계 완료
   - Pro 플랜 (₩4,900/월) 전환 시나리오
   - B2B 확장 경로 (기업/독서클럽)

### 피치 톤 & 매너
- **자신감 있되 겸손하게**: "이미 만들었고, 더 빠르게 갈 준비가 되었다"
- **데이터 중심**: 숫자로 말하기 (테이블 수, 컴포넌트 수, 커밋 밀도)
- **액션 지향**: "보여드리겠습니다" (라이브 URL로 증명)

## 3. 스크린샷 가이드

### 필요한 스크린샷 6장

실제 서비스에서 캡처해야 할 핵심 화면:

| # | 화면 | 캡처 포인트 | 강조할 것 |
|---|------|-----------|----------|
| 1 | **대시보드** | 전체 레이아웃 | 습관 트래커, 레벨, 인사말 |
| 2 | **서재** | 책 목록 + 필터 | 읽기 상태별 분류, 카드 UI |
| 3 | **노트 작성** | 인용 노트 편집 | 5종 타입 탭, 에디터 |
| 4 | **AI OCR** | 사진 업로드 → 결과 | OCR 전/후 비교 |
| 5 | **AI 채팅** | 대화 진행 중 | 페르소나 반영, 책 추천 |
| 6 | **독서 모임** | 모임 대시보드 | 지정도서, 멤버 활동 |

### 캡처 가이드라인

- **해상도**: 1280x800 이상 (Retina 권장)
- **브라우저**: Chrome, 깨끗한 프로필 (북마크바 숨김)
- **데이터**: 실제적이고 풍성한 더미 데이터 필수
  - 대시보드: 레벨 5 이상, 연속 기록 7일+
  - 서재: 최소 10권 (다양한 읽기 상태)
  - 노트: 실제 책 내용 기반 의미있는 인용
- **포맷**: PNG, 투명 배경 없음
- **파일명 규칙**: `screenshot-{번호}-{화면명}.png`
  - 예: `screenshot-01-dashboard.png`

### 스크린샷 교체 방법

HTML 파일 내 각 목업 위치에 주석으로 가이드 포함:
```html
<!-- SCREENSHOT: screenshot-01-dashboard.png -->
<!-- 이 div를 <img src="screenshot-01-dashboard.png"> 로 교체 -->
```

교체 절차:
1. `doc/vc/` 폴더에 스크린샷 파일 배치
2. HTML 내 해당 `div.screenshot-mockup`을 `<img>` 태그로 교체
3. 또는 CSS `background-image`로 설정
