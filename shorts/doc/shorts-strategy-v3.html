핵심 랭킹 팩터 (우선순위순)

  1. 시청 유지율(Retention) — 30초 Shorts 85% 유지 > 60초 50% 유지
  2. 스와이프 행동(Swipe-through Rate) — 첫 3초 내 이탈 여부가 결정적
  3. 루프율(Loop Rate) — 반복 재생은 가장 강력한 양성 신호
  4. 공유(Shares) — 평균 이상 공유 수 → 기하급수적 도달 확장
  5. 댓글/좋아요/구독 — 상호작용 참여도

참고: 업로드 시간은 직접적인 랭킹 팩터가 아님. 시청자 반응이 결정적.

독서/교육 콘텐츠 (BookTok/북튜브) 트렌드

BookTok 현황

BookTok은 TikTok에서 시작된 독서 커뮤니티로, 2024년 기준 #BookTok 해시태그 조회수 2,300억 이상을 기록했습니다. 2025~2026년에는 YouTube Shorts와 Instagram Reels로도 확산되어 '북튜브 숏폼'이 하나의 장르로 자리잡았습니다.

인기 콘텐츠 유형

  • 감정 리뷰 — 책을 읽고 운 장면, 감동받은 순간을 담은 리액션형 콘텐츠
  • 서재 공개(Shelfie) — 나만의 책장을 보여주는 ASMR/미학적 콘텐츠
  • 독서 브이로그 — "오늘 하루 독서 루틴" 형식의 일상 콘텐츠
  • 추천 리스트 — "이 주제라면 이 5권" 큐레이션형
  • 독서 챌린지 — 월간/연간 독서 목표 달성 과정 공유

Habitree 적용 포인트

  • 앱 내 독서 기록 데이터를 활용한 자동 콘텐츠 생성
  • 사용자 서재(가상 책장) 시각화 쇼츠
  • 독서모임 활동 하이라이트 자동 편집
  • 월간 독서 통계 인포그래픽 쇼츠

도파민 루프와 숏폼 시청 심리

숏폼 콘텐츠는 뇌의 도파민 보상 회로를 자극합니다. 짧은 영상을 시청하면 소량의 도파민이 분비되고, 다음 영상에 대한 기대감(불확실성의 보상)이 스와이프 행동을 유발합니다.

도파민 루프 구조

1
기대(Anticipation) — 새 영상에 대한 기대감이 도파민 분비를 시작
2
시청(Consumption) — 짧은 콘텐츠로 즉각적 만족감 제공
3
변동 보상(Variable Reward) — 다음 콘텐츠의 불확실성이 중독성 유발
4
스와이프(Action) — 다음 영상으로의 자동적 행동

Habitree 적용: 각 쇼츠 끝에 "다음 편에서..." 식의 호기심 유발 요소를 배치하여 시리즈 연속 시청을 유도. 변동 보상 원리를 활용해 매번 다른 포맷/정보를 제공.

행동 경제학 전략

넛지(Nudge) 전략

  • 디폴트 효과 — CTA를 "앱 다운로드"가 아닌 "무료로 기록 시작하기"로 프레이밍
  • 앵커링 — "하루 5분이면 충분합니다" 같은 낮은 진입 장벽 제시
  • 프레이밍 — "200권 읽은 사람들의 비밀" (손실 회피 자극)

사회적 증거(Social Proof)

  • 숫자 활용 — "3만 명이 사용하는 독서 앱"
  • 사용자 후기 — 실제 사용자의 Before/After 스토리
  • 커뮤니티 활동 — "이번 달 1,200개 독서모임 진행"

FOMO(Fear Of Missing Out) 전략

  • 독서 챌린지 — "3월 독서 챌린지에 2,000명이 참여 중!" → 참여 유도
  • 독서모임 — "이번 주 인기 독서모임 TOP 5" → 제한된 참여감
  • 통계 공유 — "이번 달 한국인 평균 독서량을 넘은 사람은 23%뿐" → 도전 의식

스토리텔링 심리학

내러티브 전이(Narrative Transportation)

시청자가 스토리에 몰입하면 비판적 사고가 감소하고 메시지 수용도가 높아집니다. 숏폼에서는 45초 이내에 완결된 스토리 아크를 만들어야 합니다.

Hook Model 적용

Nir Eyal의 Hook Model을 숏폼 콘텐츠에 적용하여 습관적 시청 → 앱 전환을 유도합니다.

단계일반 설명Habitree 쇼츠 적용
트리거(Trigger) 외부/내부 자극으로 행동 시작 알고리즘 추천 노출 (외부) + "독서 기록 정리하고 싶다" (내부)
행동(Action) 보상을 기대하며 행동 쇼츠 시청 (최소한의 노력, 즉각적 콘텐츠 소비)
변동 보상(Variable Reward) 예측 불가한 보상 제공 매번 다른 책/팁/스토리 제공, "오늘은 무슨 콘텐츠일까?" 기대감
투자(Investment) 미래 보상을 위한 투자 앱 다운로드, 독서 기록 시작, 독서모임 참여 (CTA)

시리즈별 컬러 전략

  • 정보형 (tip, feature-demo) — Forest 중심, 밝고 신뢰감 있는 톤
  • 감정형 (booktok-style, user-story) — Paper 중심, 따뜻하고 감성적 톤
  • 긴장형 (pain-point, book-vs-book) — Charcoal 중심 → Forest 전환 (문제 → 해결)
  • 커뮤니티형 (community-highlight, creator-collab) — Forest + Paper 믹스, 소속감 표현

콘텐츠 마케팅 퍼널

TOFU (Top of Funnel) — 인지 daily-quote, pain-point, booktok-style
MOFU (Middle of Funnel) — 고려 book-review, reading-tip, community-highlight
BOFU (Bottom of Funnel) — 전환 app-preview, feature-demo, user-story
Retention — 유지 reading-challenge, creator-collab, service-showcase

퍼널 전략: TOFU 콘텐츠로 대중 노출 극대화 → MOFU에서 가치 증명 → BOFU에서 구체적 기능/후기로 전환 유도 → Retention으로 이탈 방지. 전체 콘텐츠 비율은 TOFU 40%, MOFU 30%, BOFU 20%, Retention 10%.

1. user-story (사용자 변화 스토리)

45초 | Before/After 포맷
BOFU

타임라인 구성

구간시간내용비주얼
Hook0-3초"3개월 전의 저는..." (충격적 Before)어둡고 복잡한 화면
Before3-12초흩어진 메모, 정리 안 된 독서 기록흐릿한 스크린샷, 어두운 톤
전환점12-18초"그런데 Habitree를 만나고..." (트랜지션)밝아지는 화면 전환
After18-35초깔끔한 서재, 통계, 독서모임 활동밝은 Forest 톤, UI 스크린샷
CTA35-45초"당신의 독서도 변할 수 있어요" + 앱 링크로고 + QR 코드

후킹 전략 (첫 3초)

패턴 인터럽트 — 예상과 다른 부정적 이미지로 시작하여 호기심 유발. "저 3개월 동안 책 0권 읽었어요" 같은 자기 고백형.

비주얼/오디오

비주얼: 스플릿 스크린 Before/After, 어두운 Charcoal → 밝은 Forest로 전환. 오디오: 나레이션 + 감성 피아노 BGM, After 구간에서 밝은 음악으로 전환.

CTA 구조

소프트 CTA — "프로필 링크에서 무료로 시작해보세요" (강제 느낌 최소화)

AI 스크립트 고도화

페르소나별 톤 분기 시스템

// generate-script.ts 개선안
interface ScriptConfig {
  series: SeriesType;
  persona: 'record' | 'community' | 'creator';
  emotionalArc: EmotionalArc;
  platform: 'youtube' | 'tiktok' | 'reels';
}

// 감정 곡선 타입
type EmotionalArc = {
  hook: 'shock' | 'question' | 'empathy' | 'namedrop';
  tension: 'low' | 'medium' | 'high';
  climaxPosition: number; // 0-1 비율
  ctaStyle: 'soft' | 'direct' | 'dual';
};

감정 곡선 적용

  • 시리즈별 사전 정의된 EmotionalArc 템플릿 제공
  • OpenAI 프롬프트에 감정 곡선 지시어 포함
  • 스크립트 단계별 감정 강도 태깅 (0-10)
  • TTS 음성에도 감정 강도 반영 (속도, 톤 조절)

자동 자막 시스템

워드별 하이라이트 애니메이션

85%의 숏폼 시청자가 무음으로 시청하므로, 워드 단위 하이라이트 자막은 필수입니다.

구현 방식

  • 타임스탬프 추출 — TTS 생성 시 워드별 타임스탬프 함께 생성
  • Remotion 컴포넌트 — 현재 발화 단어를 하이라이트하는 <WordHighlight> 컴포넌트
  • 스타일 옵션 — 배경 하이라이트, 색상 변경, 크기 변화, 바운스 애니메이션
  • 위치 — 화면 하단 1/3, 안전 영역 내 배치

UGC 템플릿 시스템

사용자가 자신의 독서 데이터로 쇼츠를 자동 생성할 수 있는 "공유 카드" 시스템입니다.

제공 템플릿

  • 월간 독서 리포트 — 읽은 책, 페이지 수, 좋아한 장르를 인포그래픽으로
  • 서재 공개 — 나의 가상 책장을 3D 회전 뷰로
  • 독서 타임라인 — 올해 읽은 책을 시간순 스크롤 영상으로
  • 명언 카드 — 내가 하이라이트한 문장을 예쁜 카드 영상으로

기술 구현

Remotion Player를 웹 앱에 임베드하여 실시간 프리뷰 → 서버리스 렌더링(Remotion Lambda) → 다운로드/공유 링크 제공. Habitree 워터마크가 자연스럽게 포함되어 바이럴 효과.

루프형 편집 & 트렌딩 사운드

루프형 편집

영상의 마지막 프레임이 첫 프레임과 자연스럽게 연결되는 구조입니다.

  • 끝에서 시작으로 이어지는 카메라 무빙
  • 마지막 텍스트가 Hook 질문의 답이 되는 구조
  • 루프 감지 시 알고리즘이 "높은 재시청"으로 판단
  • Remotion에서 loop 속성 + 트랜지션 컴포넌트로 구현

트렌딩 사운드 연동

인기 BGM을 활용하면 알고리즘 노출이 크게 증가합니다.

  • TikTok Creative Center에서 트렌딩 사운드 주간 수집
  • 라이선스 프리 BGM 라이브러리 구축 (Epidemic Sound 등)
  • 시리즈별 기본 BGM + 트렌딩 사운드 믹스 옵션
  • 플랫폼별 사운드 최적화 (TikTok은 트렌딩 필수)

  • 내러티브 전이(Narrative Transportation): 스토리 몰입 시 옥시토신 분비로 공감/유대감 형성
  • 손실 회피(Loss Aversion): 사람은 이득의 기쁨보다 손실의 고통을 2배 강하게 느낌
  • 행동경제학 기반 캠페인이 전통 캠페인 대비 31% 더 높은 소비자 반응률 기록
  • 사회적 증거(Social Proof): 소비자 98%가 구매 전 리뷰 확인, "인기" 태그만으로 예약 23% 증가
  • 빠른 컷 전환이 뇌의 지향 반응(orienting response)을 활용하여 주의력 리셋
  • 2025년 메타분석: 숏폼 빈번 소비가 주의력 저하, 실행기능 감소와 상관관계 확인

쇼츠 데이터 아키텍처 개요

쇼츠 전용 Supabase 프로젝트로 모든 시리즈의 콘텐츠(문구, 에셋, 파이프라인)를 체계적으로 관리합니다.

11테이블
5레이어
14시리즈
8상태 전이

핵심 설계 결정

  • 통합 contents + JSONB: 시리즈별 테이블 분리 대신, props JSONB로 유연하게 저장. series.props_schema에 JSON Schema를 두어 유효성 보장.
  • text_fragments 분리: hook/CTA/감정태그 등 여러 시리즈에서 재사용할 수 있는 문구를 별도 관리하여 성과 기반 재활용.
  • 서비스 분리: 메인 DB(notes/books)와 쇼츠 DB를 분리하여 독립적 스케일링 및 비용 관리.

ERD — 테이블 관계도

레이어별 테이블 상세

Layer A: 시리즈/콘텐츠 관리

series — 14개 시리즈의 해상도, fps, duration, props_schema 등 메타데이터

contents — 핵심 테이블. 모든 시리즈의 콘텐츠를 JSONB props로 통합 저장. 8단계 라이프사이클 관리.

text_fragments — hook, CTA, 감정태그 등 재사용 가능한 문구. 성과 기반 자동 재활용.

Layer B: 에셋 관리

assets — 스크린샷, 오디오(TTS/BGM), 커버이미지, 영상 등 미디어 에셋 통합 관리.

content_assets — 콘텐츠와 에셋을 M:N으로 연결. role(primary, thumbnail, tts 등)로 용도 구분.

Layer C: 제작 파이프라인

pipeline_runs — 파이프라인 실행 이력. 단계별 진행 상태, OpenAI/TTS 비용 추적, 에러 로그 저장.

상태: pending → fetching → scripting → tts → rendering → post_processing → uploading → completed

Layer D: 배포/분석

publications — YouTube/TikTok/Reels 플랫폼별 배포 기록. 예약 발행 지원.

analytics_snapshots — 일별 성과 스냅샷. 조회수, 완주율, CTR 등 핵심 지표 추적.

Layer E: 템플릿/스케줄

content_templates — 시리즈별 콘텐츠 생성 템플릿. AI 프롬프트 포함하여 자동 생성 지원.

schedules — cron 기반 자동 발행 스케줄. content_strategy로 콘텐츠 선택 전략 지정.

sync_log — 메인 DB(notes/books) → 쇼츠 DB 동기화 추적 로그.
